# Protocolo: Estados Unidos (US) - SAT/Common Core

## Sistema Educativo
- **Estructura:** Elementary School (K-5), Middle School (6-8), High School (9-12)
- **Curriculum:** Common Core State Standards (CCSS) + State Standards
- **Exámenes clave:** SAT/ACT (Grade 11-12), AP Exams, State Assessments
- **Equivalente ICFES:** SAT (College Board) para Grade 11
- **Ciclo:** K-12 (13 años de educación obligatoria)

## Calendario Académico US
- **Inicio:** Agosto-Septiembre
- **Periodos:** 4 quarters o 2 semesters (~9 semanas cada uno)
- **Fin:** Mayo-Junio
- **Descansos:** Winter Break (Dec), Spring Break (Mar-Apr), Summer (Jun-Aug)
- **Semanas lectivas:** ~40 semanas (W01-W40)

## Coding Guidelines
- **Country code:** `US` → directory `questions_data/usa/`
- **Subject:** `mathematics`, `ela`, `science`, `social-studies`, `esl`
- **Grade level folders:** `grado-11` (SAT prep focus)
- **ID format:** `US-{SUBJ}-11-2026-W{NN}-{topic}-001-MASTERY`
- **CEFR field:** Set for ESL only (A1, A2, B1, B2, C1, C2)
- **Language:** English (US) for all subjects
- **Modern contexts:** Use US cities, culture, real-world scenarios

## Curriculum Alignment
- **Math:** CCSS.Math.Content.HSA, HSF (High School Algebra, Functions)
- **ELA:** CCSS.ELA-Literacy.RL.11-12, RI.11-12, W.11-12
- **Science:** NGSS High School Standards
- **Social Studies:** C3 Framework + NCSS Standards
- **ESL:** WIDA ELD Standards / CEFR Framework
