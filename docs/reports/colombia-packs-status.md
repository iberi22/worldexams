## 🤖 Instrucciones para Generación Automatizada

### Protocolo v2.0

Cada pack debe contener **7 preguntas** con esta distribución:

| # | Tipo | Dificultad | ID Suffix |
|---|------|------------|-----------|
| 1 | Original | 3 (Media) | `-v1` |
| 2 | Fácil A | 1-2 | `-v2` |
| 3 | Fácil B | 1-2 | `-v3` |
| 4 | Media A | 3 | `-v4` |
| 5 | Media B | 3 | `-v5` |
| 6 | Difícil A | 4-5 | `-v6` |
| 7 | Difícil B | 4-5 | `-v7` |

### Formato de ID

```
CO-[ASIGNATURA]-[GRADO]-[TEMA]-[###]-v[1-7]
```

**Ejemplos:**
- `CO-MAT-09-algebra-001-v1` (Matemáticas Grado 9, tema álgebra, pack 1, pregunta 1)
- `CO-LEN-05-comprension-002-v3` (Lenguaje Grado 5, tema comprensión, pack 2, pregunta 3)
- `CO-CIU-09-constitucion-001-v7` (Ciudadanas Grado 9, tema constitución, pack 1, pregunta 7)
