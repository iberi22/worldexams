## 📐 Major Entrance Exams Structure

### 1. JEE Main (Engineering)
- **Subjects:** Physics, Chemistry, Mathematics.
- **Format:** 90 Questions (30 per subject).
- **Grading:** +4 for correct, -1 for incorrect. Total 300 marks.
- **Purpose:** Admission to NITs, IIITs, and eligibility for JEE Advanced (for IITs).

### 2. NEET (Medical)
- **Subjects:** Physics, Chemistry, Biology (Botany & Zoology).
- **Format:** 200 Questions (180 to be attempted).
- **Grading:** +4 for correct, -1 for incorrect. Total 720 marks.

### 3. CUET (Common University Entrance Test)
- **Structure:** Language, Domain-Specific subjects, and General Test.
- **Grading:** +5 for correct, -1 for incorrect.
