## 📐 Prueba Saber (ICFES)
Examen nacional estandarizado para el ingreso a la educación superior.
- **Áreas Evaluadas:** Lectura Crítica, Matemáticas, Ciencias Naturales, Sociales y Ciudadanas, Inglés.
