# Community Curation & Global Expansion Protocol

> **Goal**: To build the largest, highest-quality curated question bank in human history.

## 1. Project Vision
World Exams aims to democratize high-stakes assessment preparation. By exposing our internal **Generation Protocols** (V5.1 Mastery and beyond), we empower the community to build, audit, and refine educational content at scale.

## 2. The ">10 Feedback" Rule
To ensure institutional-grade quality, every community-submitted or AI-generated question in the "Shadow Pool" must pass a validation threshold:
- **Public Promotion**: A question becomes "Public" and official only after receiving **>10 positive pedagogical feedbacks**.
- **Pedagogical Feedback**: Feedbacks must include error analysis or reasoning verification (meritocratic system).
- **Shadow Node**: Questions in incubation are stored in a dedicated shadow pool before being merged into the master branch.

## 3. Community Prompt Sandbox
We will provide a public interface with an **Adaptable Prompt Sandbox**.
- **Input**: Users provide a raw subject or draft question.
- **Engine**: The system applies the active `Mastery` protocols (distractor analysis, feedback per option, Bloom alignment).
- **Output**: A standardized bundle ready for peer review.

## 4. Globalization & Localization Workflow
Every curated question is subject to the **Translator/Synchronizer** loop:
1. **Source**: Colombian mastery question.
2. **Translation**: High-fidelity translation (English, Portuguese, etc.).
3. **Localization**: Adaptation of cultural contexts (monkeys -> penguins if relevant, currency, regional names) while preserving the pedagogical intent.
4. **Validation**: Local educators audit the localized version before final approval.

## 5. Open Protocol Transparency
The protocols used by this AI (found in `docs/QUESTION_GENERATION_PROTOCOL_V5.md`) are the same ones offered to the community. This ensures consistency between AI-generated and human-generated content.
