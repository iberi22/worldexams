# Estrategia de Licenciamiento "World Exams"

Este documento define la estrategia final de licenciamiento para cumplir con el objetivo: **"Contenido libre para aprender, Plataforma protegida para emprender (solo World Exams)".**

## 1. Código Fuente de la Plataforma (Software)
**Licencia:** [PolyForm Shield License 1.0.0](https://polyformproject.org/licenses/shield/1.0.0/)

*   **¿Qué permite?** Cualquiera puede ver el código, descargarlo, modificarlo y usarlo para fines personales o internos.
*   **¿Qué prohíbe?** Prohíbe explícitamente usar el software para competir con World Exams. Es decir, **nadie puede montar un servicio de exámenes idéntico y cobrar por él** usando nuestro código.
*   **Texto Clave (Resumen):** "Usted no puede usar este software para competir con el licenciante."

## 2. Contenido Educativo (Banco de Preguntas)
**Licencia:** [Creative Commons Attribution-NonCommercial-ShareAlike 4.0 (CC BY-NC-SA 4.0)](https://creativecommons.org/licenses/by-nc-sa/4.0/)

*   **¿Qué permite?** Estudiantes y profesores pueden usar, copiar y adaptar las preguntas libremente.
*   **¿Qué prohíbe?** El uso comercial. Nadie puede vender paquetes de nuestras preguntas ni incluirlas en libros o apps de pago sin permiso.
*   **Integridad:** Cualquier obra derivada debe mantenerse libre (ShareAlike).

## 3. Plan Institucional (Modelo de Negocio)
El código en `src/lib/institutional-service.ts` y los módulos relacionados con "Salas de Examen" (`Exam Room`) son la base del servicio comercial.
*   **Instituciones:** Pagan por funciones avanzadas (gestión de grupos, analíticas avanzadas, soporte).
*   **Monopolio Técnico:** Gracias a la licencia PolyForm Shield, somos los únicos autorizados legalmente para vender este servicio "SaaS" basado en el código.
