**Contexto:** Un estudiante reflexiona sobre el valor absoluto como una propiedad de los numeros reales que representa distancia.

### Enunciado
Si $|x - 3| < 5$, ¿cual es el rango de valores posibles para el numero real $x$?

### Opciones
- [ ] A) $x < 8$ <!-- feedback: Falta el limite inferior. -->
- [x] B) $-2 < x < 8$ <!-- feedback: ¡Correcto! La distancia entre x y 3 es menor que 5, lo que implica 3-5 < x < 3+5. -->
- [ ] C) $x > -2$ <!-- feedback: Falta el limite superior. -->
- [ ] D) $2 < x < 8$ <!-- feedback: Error en el calculo del limite inferior. -->

### Explicacion Pedagogica
La desigualdad $|x - a| < d$ se traduce como $a - d < x < a + d$. En este caso, $3 - 5 < x < 3 + 5$, lo que resulta en el intervalo $(-2, 8)$. Esto muestra como el valor absoluto define vecindades o entornos en la recta real.
