### Explicacion Pedagogica
Para racionalizar un denominador binomio con raíces cuadradas, multiplicamos tanto el numerador como el denominador por el conjugado del denominador. El conjugado de (√x - 2) es (√x + 2). Numerador: 1 * (√x + 2) = √x + 2. Denominador: (√x - 2)(√x + 2) = (√x)² - 2² = x - 4. El resultado es (√x + 2) / (x - 4).
