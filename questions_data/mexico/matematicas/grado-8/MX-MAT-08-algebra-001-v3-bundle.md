## Pregunta 8 (Difícil B - Dificultad 4)

**ID:** `MX-MAT-08-algebra-001-v8`

### Enunciado

¿Cuál es el resultado de (2x + 3)(x - 1)?

### Opciones

- [x] A) 2x² + x - 3
- [ ] B) 2x² - x - 3
- [ ] C) 2x² + 3x - 3
- [ ] D) 2x² - 3

### Explicación Pedagógica

Multiplicamos término a término: 2x(x) + 2x(-1) + 3(x) + 3(-1) = 2x² - 2x + 3x - 3 = 2x² + x - 3.

## Pregunta 9 (Muy Difícil A - Dificultad 5)

**ID:** `MX-MAT-08-algebra-001-v9`

### Enunciado

En un examen de 20 preguntas, cada respuesta correcta suma 5 puntos y cada incorrecta resta 2 puntos. Si un estudiante obtuvo 72 puntos, ¿cuántas preguntas contestó correctamente?

### Opciones

- [x] A) 16
- [ ] B) 14
- [ ] C) 15
- [ ] D) 18

### Explicación Pedagógica

Planteamos el sistema: c + i = 20 y 5c - 2i = 72. De la primera i = 20 - c. Sustituimos: 5c - 2(20 - c) = 72 -> 5c - 40 + 2c = 72 -> 7c = 112 -> c = 16.

## Pregunta 10 (Muy Difícil B - Dificultad 5)

**ID:** `MX-MAT-08-algebra-001-v10`

### Enunciado

¿Cuál es el valor de x que satisface la ecuación: (x/2) + (x/3) = 10?

### Opciones

- [x] A) x = 12
- [ ] B) x = 6
- [ ] C) x = 20
- [ ] D) x = 15

### Explicación Pedagógica

Buscamos común denominador (6): (3x/6) + (2x/6) = 10 -> 5x/6 = 10 -> 5x = 60 -> x = 12.
