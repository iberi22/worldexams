## Pregunta 1 (Muy Fácil A - Dificultad 1)

**ID:** `MX-MAT-09-algebra-001-v1`

### Enunciado

¿Cuál de las siguientes es una ecuación de segundo grado (cuadrática)?

### Opciones

- [x] A) x² + 5x + 6 = 0
- [ ] B) 3x - 4 = 10
- [ ] C) x + y = 5
- [ ] D) 2x = 8

### Explicación Pedagógica

Una ecuación de segundo grado es aquella donde el exponente más alto de la incógnita es 2.

## Pregunta 4 (Fácil B - Dificultad 2)

**ID:** `MX-MAT-09-algebra-001-v4`

### Enunciado

¿Cuál es el resultado de (x + 4)²?

### Opciones

- [x] A) x² + 8x + 16
- [ ] B) x² + 16
- [ ] C) x² + 4x + 8
- [ ] D) 2x + 8

### Explicación Pedagógica

Es un binomio al cuadrado: (a+b)² = a² + 2ab + b². Entonces x² + 2(4x) + 4² = x² + 8x + 16.

### Enunciado

¿Cuál es el valor del discriminante (b² - 4ac) en la ecuación x² - 4x + 4 = 0?

### Opciones

- [x] A) 0
- [ ] B) 16
- [ ] C) 8
- [ ] D) -16

### Explicación Pedagógica

Sustituimos: a=1, b=-4, c=4. (-4)² - 4(1)(4) = 16 - 16 = 0.

## Pregunta 7 (Difícil A - Dificultad 4)

**ID:** `MX-MAT-09-algebra-001-v7`

### Enunciado

Usa la fórmula general para encontrar las soluciones de: x² - 5x + 6 = 0

### Opciones

- [x] A) x = 2, x = 3
- [ ] B) x = -2, x = -3
- [ ] C) x = 1, x = 6
- [ ] D) x = 5, x = 6

### Explicación Pedagógica

**Paso 1:** Identificar a=1, b=-5, c=6.
**Paso 2:** Aplicar x = [-(-5) ± √((-5)² - 4(1)(6))] / 2(1) = [5 ± √(25 - 24)] / 2 = [5 ± 1] / 2.
**Resultado:** x₁ = 6/2 = 3; x₂ = 4/2 = 2.

### Enunciado

El área de un cuadrado es de 144 cm². Si x representa la medida de su lado, ¿cuál es la ecuación que permite encontrar x y cuánto mide el lado?

### Opciones

- [x] A) x² = 144; x = 12 cm
- [ ] B) 4x = 144; x = 36 cm
- [ ] C) x² = 144; x = 72 cm
- [ ] D) 2x = 144; x = 72 cm

### Explicación Pedagógica

El área de un cuadrado es lado al cuadrado (x²). Por lo tanto x² = 144. La raíz cuadrada de 144 es 12.

## Pregunta 9 (Muy Difícil A - Dificultad 5)

**ID:** `MX-MAT-09-algebra-001-v9`

### Enunciado

El producto de dos números enteros consecutivos es 156. ¿Cuál es la ecuación cuadrática que representa este problema?

### Opciones

- [x] A) x² + x - 156 = 0
- [ ] B) x² + x + 156 = 0
- [ ] C) 2x + 1 = 156
- [ ] D) x² + 2x - 156 = 0

### Explicación Pedagógica

Sean los números x y (x + 1). Su producto es x(x + 1) = 156. Desarrollando: x² + x = 156, lo que equivale a x² + x - 156 = 0.

## Pregunta 10 (Muy Difícil B - Dificultad 5)

**ID:** `MX-MAT-09-algebra-001-v10`

### Enunciado

Si una función cuadrática es f(x) = x² - 4x + 3, ¿cuál es la coordenada del vértice de la parábola?

### Opciones

- [x] A) (2, -1)
- [ ] B) (4, 3)
- [ ] C) (-2, 15)
- [ ] D) (2, 3)

### Explicación Pedagógica

La coordenada x del vértice es -b/2a = -(-4)/2(1) = 4/2 = 2. Para y: f(2) = (2)² - 4(2) + 3 = 4 - 8 + 3 = -1. El vértice es (2, -1).
