## Question 1 [D3-D4] (Variant Basic - Difficulty 3)

**ID:** `CL-MAT-10-P1-algebra-001-v1`
**Bloom:** Apply
**ICFES:** Modelación
**Context:** Un completo italiano cuesta $2.500 y cada ingrediente extra cuesta $x$. Si Diego compra un completo con 3 extras y paga $3.850, ¿cuál es la ecuación que modela la situación?

### Enunciado
¿Cuál de las siguientes ecuaciones permite encontrar el valor de cada ingrediente extra $x$?

### Options
- [ ] A) $2.500x + 3 = 3.850$ <!-- feedback: Incorrecto. Aquí se multiplica el precio base por el valor del extra, lo cual no tiene sentido. -->
- [x] B) $2.500 + 3x = 3.850$ <!-- feedback: Correcto. El costo total es el precio base más 3 veces el valor de cada extra. -->
- [ ] C) $3(2.500 + x) = 3.850$ <!-- feedback: Incorrecto. Esto indicaría que compró 3 completos con un extra cada uno. -->
- [ ] D) $x + 3 \cdot 2.500 = 3.850$ <!-- feedback: Incorrecto. Aquí se multiplican los completos por 3, pero solo compró uno. -->

### Explicación Pedagógica
La situación describe un costo fijo (el completo) y un costo variable (los extras). La estructura lineal estándar es $C = F + Vx$, donde $F$ es el costo fijo y $V$ la cantidad de extras.
