## Question 1 [D3-D4]

**Bloom Level:** Remember
**Competencia:** Identificar expresiones algebraicas equivalentes
**Contexto:** Un estudiante está resolviendo ejercicios de simplificación en su cuaderno de matemáticas

**Enunciado:** ¿Cuál de las siguientes expresiones representa correctamente el desarrollo de (x + 3)²?

**Opciones:**
A. x² + 9
B. x² + 6x + 9 [x]
C. x² + 6x + 6
D. 2x + 6

**Explicación Pedagógica:**
La respuesta correcta es B porque corresponde al producto notable (a + b)² = a² + 2ab + b², donde 2(x)(3) = 6x y 3² = 9. El distractor A omite el término del producto cruzado, error común al desarrollar sin aplicar la fórmula completa. El distractor C confunde el segundo término del resultado. El distractor D corresponde a una expresión lineal incorrecta.

## Question 3 [D3-D4]

**Bloom Level:** Understand
**Competencia:** Comprender el concepto de valor numérico de una expresión algebraica
**Contexto:** Un estudiante debe evaluar expresiones en una evaluación del primer trimestre

**Enunciado:** Si x = -2 e y = 3, ¿cuál es el valor de 2x² - 3y?

**Opciones:**
A. -5
B. 17 [x]
C. -1
D. 5

**Explicación Pedagógica:**
La respuesta correcta es B porque 2(-2)² - 3(3) = 2(4) - 9 = 8 - 9 = -1... espere, el cálculo correcto es 8 - 9 = -1, entonces la respuesta debería ser A. Revisando: 2x² = 2(4) = 8, -3y = -9, resultado = -1. El distractor correcto es A. Los distractores B y D surgen de errores en el orden de operaciones o signos.

**Corrección:** La respuesta correcta es A. El distractor B surge de no considerar el signo negativo de y. El distractor D resulta de sumar en lugar de restar.

## Question 5 [D5-D6]

## Question 7 [D5-D6]

**Bloom Level:** Apply
**Competencia:** Resolver ecuaciones de primer grado con una incógnita
**Contexto:** Un problema de la vida cotidiana涉及 resolver una ecuación para encontrar un valor desconocido

**Enunciado:** Si 3(x - 2) + 4 = 2x + 5, ¿cuál es el valor de x?

**Opciones:**
A. x = 7
B. x = 5 [x]
C. x = 3
D. x = -1

**Explicación Pedagógica:**
La respuesta correcta es B. Desarrollando: 3x - 6 + 4 = 2x + 5 → 3x - 2 = 2x + 5 → 3x - 2x = 5 + 2 → x = 7... verificando: 3(7-2)+4 = 3(5)+4 = 15+4=19, 2(7)+5=14+5=19. La respuesta correcta es A. El distractor B surge de error al trasponer términos. El distractor C de distribución incorrecta. El distractor D de cambio de signo incorrecto.

**Corrección:** La respuesta correcta es A. x = 7.

## Question 8 [D5-D6]

**Opciones:**

B. x ≤ -6 [x]

**Explicación Pedagógica:**
La respuesta correcta es B. Restando 2x de ambos lados: -5 ≤ x + 1, luego restando 1: -6 ≤ x, equivalente a x ≥ -6... esto daría A. Verificando: -6 ≤ x es lo mismo que x ≥ -6. El distractor correcto es A. El error en B es invertir el signo al multiplicar por -1 incorrectamente.

## Question 9 [D5-D6]

**Bloom Level:** Apply
**Competencia:** Simplificar expresiones racionales algebraicas
**Contexto:** En un problema de funciones racionales, se requiere simplificar una expresión

**Enunciado:** Al simplificar (x² - 9) / (x² - 6x + 9) se obtiene:

**Opciones:**
A. (x - 3) / (x - 3)
B. (x + 3) / (x - 3) [x]
C. (x - 3) / (x + 3)
D. (x + 3) / (x + 3)

**Explicación Pedagógica:**
La respuesta correcta es B. Factorizando: x² - 9 = (x + 3)(x - 3) y x² - 6x + 9 = (x - 3)² = (x - 3)(x - 3). Cancelando (x - 3) queda (x + 3)/(x - 3). El distractor A no simplifica correctamente. El distractor C invierte los signos en el numerador. El distractor D corresponde a error de factorización.

El distractor A no proporciona verificación. El distractor C presenta un producto incorrecto. El distractor D es una afirmación sin fundamento.

**Opciones:**

## Question 20 [D9-D10]

**Bloom Level:** Evaluate
**Competencia:** Analizar y seleccionar estrategias óptimas para resolver problemas algebraicos
**Contexto:** En una evaluación de预习, se pide elegir el método más eficiente para resolver un sistema

**Enunciado:** Para resolver el sistema: 2x + y = 10 y 3x - y = 5, ¿cuál método es más eficiente?

**Opciones:**
A. Sustitución, porque permite despejar y de la primera ecuación fácilmente
B. Reducción, porque al sumar las ecuaciones se elimina y directamente [x]
C. Igualación, porque ambas ecuaciones tienen la variable y
D. Gráfico, porque así se visualizan las soluciones

**Explicación Pedagógica:**
La respuesta correcta es B. Sumando ambas ecuaciones: (2x + y) + (3x - y) = 10 + 5 → 5x = 15 → x = 3, eliminando y sin necesidad de preparar las ecuaciones. El distractor A es válido pero requiere más pasos. El distractor C no es ventajoso aquí. El distractor D es impreciso para valores exactos.
