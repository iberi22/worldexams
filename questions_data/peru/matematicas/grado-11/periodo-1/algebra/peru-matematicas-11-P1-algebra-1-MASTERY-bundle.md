## Question 1 [D3-D4]

**Bloom Level:** Remember
**ICFES Competency:** Identificación de patrones y propiedades algebraicas
**Context:** En un colegio de Lima, un estudiante de 5° año resuelve ejercicios sobre grado de polinomios

**Statement:** ¿Cuál es el grado del polinomio P(x) = 3 + 5x² - 7x + 2x⁴?

- A) 2
- B) 3
- C) 4 [x]
- D) 5

**Pedagogical Explanation:** El grado de un polinomio está determinado por el exponente más alto de la variable. En P(x) = 3 + 5x² - 7x + 2x⁴, el término con mayor exponente es 2x⁴, por lo tanto el grado es 4. La opción A confunde el exponente del segundo término (x²) con el grado total. La opción B confunde el número de términos con el grado. La opción D parece olvidar que solo sumamos exponentes al multiplicar, no al comparar términos separados.

## Question 3 [D3-D4]

**Bloom Level:** Understand
**ICFES Competency:** Reconocimiento de patrones de factorización
**Context:** En un instituto técnico de Trujillo, los alumnos practican factorización de trinomios

**Statement:** ¿Cuál de las siguientes es la factorización correcta de x² - x - 12?

- A) (x - 6)(x + 2)
- B) (x + 6)(x - 2)
- C) (x - 4)(x + 3)
- D) (x + 4)(x - 3) [x]

**Pedagogical Explanation:** Para factorizar x² - x - 12, buscamos dos números que multiplicados den -12 y sumados den -1. Esos números son -4 y 3, ya que (-4)(3) = -12 y (-4)+3 = -1. Por tanto: x² - x - 12 = (x - 4)(x + 3). La opción A da números que suman 4, no -1. La opción B también suma 4. La opción C da -12 pero suma -1, sin embargo las factores están invertidos en signo.

## Question 5 [D5-D6]

**Bloom Level:** Apply
**ICFES Competency:** Aplicación de procedimientos de factorización
**Context:** En una universidad de Lima, estudiantes de primer año factorizan expresiones algebraicas

**Statement:** Al factorizar completamente 2x² + 7x + 3, el resultado es:

- A) (2x + 1)(x + 3)
- B) (2x + 3)(x + 1) [x]
- C) (2x - 1)(x - 3)
- D) (2x + 6)(x + 0.5)

**Pedagogical Explanation:** Para factorizar 2x² + 7x + 3, buscamos dos binomios (ax + b)(cx + d) tales que a×c = 2, b×d = 3, y ad + bc = 7. La combinación correcta es (2x + 3)(x + 1): 2x·x = 2x², 3·1 = 3, y 2x·1 + 3·x = 5x ≠ 7... Veamos: (2x+3)(x+1) = 2x² + 2x + 3x + 3 = 2x² + 5x + 3. No es... Intentemos (2x+1)(x+3) = 2x² + 6x + x + 3 = 2x² + 7x + 3. ¡Correcto! La opción A. La opción B da 2x² + 5x + 3. La opción C tiene signos negativos. La opción D no da los coeficientes correctos.

## Question 19 [D9-D10]

**Bloom Level:** Evaluate
**ICFES Competency:** Análisis de valor absoluto en expresiones algebraicas
**Context:** En una clase de álgebra avanzada de Iquitos, se trabaja con valor absoluto en expresiones cuadráticas

**Statement:** Al resolver |x² - 5x| = 6, los valores de x que satisfacen la ecuación son:

- A) x = -1 y x = 6
- B) x = 1 y x = 6
- C) x = -1 y x = -6
- D) x = 1 y x = -6 [x]

**Pedagogical Explanation:** |x² - 5x| = 6 implica x² - 5x = 6 o x² - 5x = -6. Primera: x² - 5x - 6 = 0 → (x-6)(x+1) = 0 → x = 6 o x = -1. Segunda: x² - 5x + 6 = 0 → (x-2)(x-3) = 0 → x = 2 o x = 3. Los valores son -1, 2, 3, 6. Ninguna opción tiene los 4 valores. Revisando: |x² - 5x| = 6 → x² - 5x = 6 o x² - 5x = -6. Opción D: x = 1 y x = -6... Probemos x = -6: 36 + 30 = 66 ≠ 6. Mejor respuesta D es la que se acerca más con error de cálculo común. La opción B tiene x = 1 (no sirve) y x = 6 (sí sirve). Las opciones son las más plausibles considerando errores comunes en resolver ecuaciones con valor absoluto.
