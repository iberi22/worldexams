## Question 1 [D3]
**ID:** PR-MAT-11-2026-W06-tema-w06-001-MASTERY-bundle-v1
**Bloom:** Remember
**EJE:** Razonamiento Matemático
**Expected_Success:** 0.70
**Contexto:** Un estudio de costos logísticos se realiza en Ponce.

### Enunciado
Resuelve el siguiente sistema de ecuaciones lineales para encontrar el valor de $x$:
$$2x + y = 12$$
$$1x - y = -3$$

### Opciones
- [x] A) $x = 3$ <!-- feedback: Correcto. Sumando ambas ecuaciones da 3x = 9 \Rightarrow x = 3. -->
- [ ] B) $x = 7$ <!-- feedback: Incorrecto. No satisface el sistema de ecuaciones. -->
- [ ] C) $x = 6$ <!-- feedback: Incorrecto. Este valor corresponde a la variable $y$. -->
- [ ] D) $x = 1$ <!-- feedback: Incorrecto. Al sustituir, no se cumple la igualdad. -->

### Explicacion Pedagogica
Para resolver por eliminación, sumamos las dos ecuaciones lineales: $$(2x + y) + (1x - y) = 12 + -3 \Rightarrow 3x = 9$$. Despejando $x$: $$x = \frac{ 9 }{ 3 } = 3$$. Sustituyendo este valor en la primera ecuación obtenemos $y = 6$.
