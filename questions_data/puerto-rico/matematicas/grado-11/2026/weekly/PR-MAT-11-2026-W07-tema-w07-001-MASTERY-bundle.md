## Question 1 [D3]
**ID:** PR-MAT-11-2026-W07-tema-w07-001-MASTERY-bundle-v1
**Bloom:** Remember
**EJE:** Razonamiento Matemático
**Expected_Success:** 0.70
**Contexto:** En un control de presupuesto agrícola en San Juan.

### Enunciado
Resuelve la siguiente inecuación de primer grado para la variable $x$:
$$2x + 3 < 7$$

### Opciones
- [x] A) $x < 2$ <!-- feedback: Correcto. Al restar 3 y dividir entre 2 obtenemos $x < 2$. -->
- [ ] B) $x > 2$ <!-- feedback: Incorrecto. Se cambió de forma errónea el sentido de la desigualdad. -->
- [ ] C) $x < 0$ <!-- feedback: Incorrecto. Error de cálculo en la división. -->
- [ ] D) $x \le 2$ <!-- feedback: Incorrecto. La desigualdad debe ser estricta. -->

### Explicacion Pedagogica
Para resolver la inecuación lineal $$2x + 3 < 7$$, primero restamos 3 en ambos lados: $$2x < 7 - 3 \Rightarrow 2x < 4$$. Dividimos entre 2 para despejar $x$: $$x < \frac{ 4 }{ 2 } \Rightarrow x < 2$$. Como el divisor es positivo, el sentido de la desigualdad se mantiene igual.
