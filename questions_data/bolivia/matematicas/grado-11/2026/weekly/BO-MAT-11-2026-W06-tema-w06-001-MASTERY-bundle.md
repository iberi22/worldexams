**Contexto:** En Santa Cruz, el estudiante Roxana del Colegio Nacional Santa Cruz resuelve sistemas de ecuaciones lineales para optimizar costos de materiales.

### Enunciado
¿Qué representa geométricamente la solución única de un sistema de dos ecuaciones lineales con dos variables en el plano real?

### Opciones
- [x] A) El punto de intersección de las dos rectas representadas por las ecuaciones. <!-- feedback: ¡Correcto! Cada ecuación lineal describe una recta en R^2. Si el sistema tiene solución única, es el punto exacto donde ambas rectas se cruzan. -->
- [ ] B) Dos rectas paralelas que nunca se cruzan en el plano real. <!-- feedback: Incorrecto. Si las rectas son paralelas y no se cruzan, el sistema no tiene solución (es incompatible). -->
- [ ] C) Dos rectas coincidentes que se superponen completamente. <!-- feedback: Incorrecto. Si coinciden, hay infinitas soluciones (sistema compatible indeterminado), no una solución única. -->
- [ ] D) Una parábola que intercepta al eje horizontal. <!-- feedback: Incorrecto. Las ecuaciones lineales definen líneas rectas, no curvas parabólicas de segundo grado. -->

### Explicacion Pedagogica
Cada ecuación lineal en dos variables representa una recta. El conjunto de soluciones de un sistema 2x2 corresponde a la intersección geométrica de estas dos rectas. Si existe solución única, las rectas son secantes y se intersectan exactamente en un punto.

### Enunciado

### Opciones
- [x] A) El sistema es incompatible (no tiene solución real alguna). <!-- feedback: ¡Correcto! Una contradicción numérica indica que las dos ecuaciones representan rectas paralelas y por tanto no se interceptan. -->
- [ ] B) El sistema tiene infinitas soluciones complejas. <!-- feedback: Incorrecto. Si hay contradicción, no existe ninguna combinación de valores que satisfaga ambas ecuaciones. -->
- [ ] C) La solución del sistema es el punto (0, 5) en el plano. <!-- feedback: Incorrecto. La igualdad 0 = 5 es una falsedad matemática, no representa coordenadas. -->
- [ ] D) El sistema tiene exactamente dos soluciones reales. <!-- feedback: Incorrecto. Las ecuaciones lineales en un plano nunca pueden tener exactamente dos puntos de cruce. -->

### Explicacion Pedagogica
Al obtener una identidad falsa (contradicción) durante la resolución, se demuestra que el sistema carece de soluciones comunes. Se denomina sistema incompatible o inconsistente.

**Contexto:** En El Alto, el estudiante Marisol del Colegio Nacional El Alto resuelve sistemas de ecuaciones lineales para optimizar costos de materiales.

### Enunciado
Si un sistema de dos ecuaciones lineales en dos variables tiene infinitas soluciones, ¿cómo son las rectas que representan a estas ecuaciones en el plano cartesiano?

### Opciones
- [x] A) Coincidentes (es la misma recta). <!-- feedback: ¡Correcto! Si las ecuaciones representan la misma recta, cualquier punto sobre ella satisface ambas ecuaciones, lo que genera infinitas soluciones. -->
- [ ] B) Perpendiculares entre sí. <!-- feedback: Incorrecto. Las rectas perpendiculares se cruzan en exactamente un punto, por lo que tienen solución única. -->
- [ ] C) Paralelas y distintas. <!-- feedback: Incorrecto. Las rectas paralelas distintas no se cruzan nunca y por ende el sistema no tiene solución. -->
- [ ] D) Oblicuas secantes. <!-- feedback: Incorrecto. Las secantes se cruzan en un solo punto, produciendo solución única. -->

### Explicacion Pedagogica
Un sistema compatible indeterminado posee infinitas soluciones debido a que ambas ecuaciones lineales son equivalentes y describen geométricamente a la misma recta (rectas coincidentes).

Resuelva el sistema de ecuaciones lineales: x + y = 60; 20x - 20y = 20. ¿Cuál es el valor del par (x, y)?

### Opciones
- [x] A) x = 30.5, y = 29.5 <!-- feedback: ¡Correcto! Al despejar por sustitución o reducción se obtienen estos valores exactos. -->
- [ ] B) x = 20, y = 20 <!-- feedback: Incorrecto. Estos valores no satisfacen simultáneamente la segunda ecuación lineal del sistema. -->
- [ ] C) x = 1, y = 2 <!-- feedback: Incorrecto. No satisface el valor de la primera suma del sistema. -->
- [ ] D) No tiene solución real <!-- feedback: Incorrecto. El sistema es compatible determinado, por lo que tiene solución única. -->

### Explicacion Pedagogica
Sumando o restando de forma conveniente las ecuaciones del sistema lineal se obtiene con total rigor la solución de las variables reales x e y.
