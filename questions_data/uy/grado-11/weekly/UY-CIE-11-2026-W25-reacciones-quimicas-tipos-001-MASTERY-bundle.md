  <!-- feedback: &iexcl;Correcto! -->
- [ ] **B)** No, tiene un maximo en x = 0

  <!-- feedback: Incorrecto. Revisa el concepto. -->
- [ ] **D)** Solo es correcta para x > 0
  <!-- feedback: Incorrecto. Revisa el concepto. -->

**Explicacion:** f'(x) = 2x, f'(0) = 0; f''(x) = 2 > 0, por tanto es un minimo local.
