# El texto informativo: decir hechos con claridad

## Descripción

Ocho preguntas sobre textos cortos que explican algo real: cómo se hace una cosa, dónde vive un animal, qué necesita una planta o cuánto tarda un proceso. Un texto informativo no cuenta historias: organiza información para que alguien pueda usarla.

Reconocer el instrumento que el texto nombra evita inventar utensilios. Leer los pasos uno por uno es la base para seguir bien cualquier procedimiento escrito.
