# MASTERY Bundle — Expresiones Algebraicas (001/002)

## Bloque A — Nivel D3–D5: Polinomios y Operaciones Básicas

**Contexto:** En el laboratorio de física del colegio, los estudiantes trabajan con expresiones que modelan el movimiento de objetos en caída libre desde la Torre de Baeza en Cartagena.

---

**P1.** Si la expresión $h(t) = -5t^2 + 20t + 100$ modela la altura (en metros) de un objeto thrown desde la Torre de Baeza, ¿cuál es el valor de $h(3)$?

A) $100$
B) $115$
C) $125$
D) $135$

**Respuesta: B**

---

**P2.** Dado el polinomio $P(x) = 3x^3 - 2x^2 + 5x - 4$, ¿cuál es el valor de $P(2)$?

A) $18$
B) $20$
C) $22$
D) $24$

**Respuesta: C**

---

**P3.** La expresión algebraica que representa "el triple de un número aumentado en 7" es:

A) $3x + 7$
B) $3(x + 7)$
C) $7x + 3$
D) $x^3 + 7$

**Respuesta: A**

---

**P4.** Al simplificar la expresión $4x + 5y - 2x + 3y$, se obtiene:

A) $2x + 8y$
B) $6x + 8y$
C) $2x + 2y$
D) $6x + 2y$

**Respuesta: A**

---

**P5.** El resultado de sumar $(7x^2 - 3x + 4) + (2x^2 + 5x - 1)$ es:

A) $9x^2 + 2x + 3$
B) $9x^2 - 2x + 3$
C) $5x^2 + 2x + 3$
D) $9x^2 + 2x - 3$

**Respuesta: A**

---

**P6.** Al restar $(6x^3 - 2x^2 + x) - (3x^3 + 4x^2 - 2x)$, el resultado es:

A) $3x^3 - 6x^2 + 3x$
B) $3x^3 + 2x^2 - x$
C) $9x^3 - 6x^2 + 3x$
D) $3x^3 + 6x^2 - 3x$

**Respuesta: A**

---

**P7.** El grado del polinomio $P(x) = 4x^5 - 3x^3 + 2x^2 - x + 7$ es:

A) 2
B) 3
C) 4
D) 5

**Respuesta: D**

---

**P8.** Al multiplicar $3x^2(2x^3 - 4x + 5)$, se obtiene:

A) $6x^5 - 12x^3 + 15x^2$
B) $5x^5 - x^3 + 8x^2$
C) $6x^5 + 12x^3 - 15x^2$
D) $5x^5 + 2x^3 - 2x^2$

**Respuesta: A**

---

**P9.** La expresión $(x + 3)(x - 2)$ es igual a:

A) $x^2 + x - 6$
B) $x^2 - x + 6$
C) $x^2 + x + 6$
D) $x^2 - x - 6$

**Respuesta: A**

---

**P10.** Al desarrollar $(2x + 5)^2$, se obtiene:

A) $4x^2 + 20x + 25$
B) $4x^2 + 10x + 25$
C) $2x^2 + 20x + 25$
D) $4x^2 + 25$

**Respuesta: A**

## Bloque B — Nivel D5–D7: Factorización y Productos Notables

**Contexto:** En una empresa metalmecánica de Bello, Antioquia, se fabrican piezas metálicas rectangulares. Las expresiones algebraicas representan áreas y perímetros.

---

**P11.** Al factorizar $x^2 - 9$, se obtiene:

A) $(x - 3)(x - 3)$
B) $(x + 3)(x - 3)$
C) $(x - 9)(x + 1)$
D) $(x - 3)(x + 1)$

**Respuesta: B**

---

**P12.** La factorización correcta de $x^2 + 5x + 6$ es:

A) $(x + 1)(x + 6)$
B) $(x + 2)(x + 3)$
C) $(x - 1)(x - 6)$
D) $(x - 2)(x - 3)$

**Respuesta: B**

---

**P13.** Factorizando $2x^2 + 7x + 3$:

A) $(2x + 1)(x + 3)$
B) $(2x + 3)(x + 1)$
C) $(2x - 1)(x - 3)$
D) $(2x - 3)(x - 1)$

**Respuesta: B**

---

**P14.** El producto notable $(a + b)^3$ es igual a:

A) $a^3 + 3a^2b + 3ab^2 + b^3$
B) $a^3 + a^2b + ab^2 + b^3$
C) $a^3 + 3ab + b^3$
D) $a^3 + a^2b^2 + b^3$

**Respuesta: A**

---

**P15.** Al factorizar $x^3 - 8$, se obtiene:

A) $(x - 2)(x^2 + 2x + 4)$
B) $(x + 2)(x^2 - 2x + 4)$
C) $(x - 2)(x^2 - 2x + 4)$
D) $(x - 2)(x^2 + 4)$

**Respuesta: A**

---

**P16.** La factorización de $6x^2 - 13x + 6$ es:

A) $(3x - 2)(2x - 3)$
B) $(3x + 2)(2x + 3)$
C) $(6x - 1)(x - 6)$
D) $(3x - 1)(2x - 6)$

**Respuesta: A**

---

**P17.** Al desarrollar $(x - 4)(x^2 + 4x + 16)$, se obtiene:

A) $x^3 - 64$
B) $x^3 + 64$
C) $x^3 - 16x^2 + 32x - 64$
D) $x^3 + 8x^2 + 16x - 64$

**Respuesta: A**

---

**P18.** Factorizando $x^4 - 16$:

A) $(x^2 - 4)(x^2 + 4)$
B) $(x^2 + 4)(x^2 + 4)$
C) $(x - 2)^4$
D) $(x - 4)^2(x + 4)^2$

**Respuesta: A**

## Bloque C — Nivel D7–D10: Expresiones Racionales y Problemas Complejos

**Contexto:** En la planta de tratamiento de aguas de Bogotá, el flujo de agua se modela con expresiones racionales.

---

**P19.** Simplificando la expresión racional $\frac{x^2 - 4}{x - 2}$, se obtiene:

A) $x + 2$
B) $x - 2$
C) $x^2 - 2$
D) $x^2 + 2$

**Respuesta: A**

---

**P20.** Al simplificar $\frac{x^2 + 6x + 9}{x^2 - 9}$, el resultado es:

A) $\frac{x + 3}{x - 3}$
B) $\frac{x - 3}{x + 3}$
C) $\frac{x + 3}{x + 3}$
D) $\frac{x - 3}{x - 3}$

**Respuesta: A**
