**Bloom:** Remember
**ICFES:** Algebraico
**Expected_Success:** 0.85
**Contexto:** En Bogotá, la profesora escribe en el tablero el cuadrado del binomio $(x + 3)^2$.
### Enunciado
¿Cuál es el desarrollo correcto de $(x + 3)^2$?
### Opciones
- [ ] A) $x^2 + 9$
  <!-- feedback: Incorrecto. Olvidaste el doble producto $2(x)(3) = 6x$. -->
- [x] B) $x^2 + 6x + 9$
  <!-- feedback: Correcto. $(x + 3)^2 = x^2 + 2(x)(3) + 3^2 = x^2 + 6x + 9$. -->
- [ ] C) $x^2 + 3x + 9$
  <!-- feedback: Incorrecto. El término central es $2(x)(3) = 6x$, no $3x$. -->
- [ ] D) $x^2 + 6x + 6$
  <!-- feedback: Incorrecto. El último término es $3^2 = 9$, no $6$. -->
### Explicacion Pedagogica
El cuadrado de un binomio suma es $(a + b)^2 = a^2 + 2ab + b^2$. Aquí $a = x$ y $b = 3$, por tanto $x^2 + 6x + 9$. También se verifica multiplicando $(x + 3)(x + 3)$.

## Question 11 [D9-D10]

**Contexto:** En Cúcuta, se sabe que $x^2 + y^2 = 29$ y que $xy = 10$, con $x + y$ positivo. Se quiere hallar $x + y$ sin hallar $x$ ni $y$.
### Enunciado
¿Cuál es el valor de $x + y$?
### Opciones
- [x] A) $7$
  <!-- feedback: Correcto. $(x + y)^2 = x^2 + 2xy + y^2 = 29 + 20 = 49$, luego $x + y = 7$. -->
- [ ] B) $49$
  <!-- feedback: Incorrecto. $49$ es el valor de $(x + y)^2$; falta extraer la raíz cuadrada. -->
- [ ] C) $9$
  <!-- feedback: Incorrecto. $9^2 = 81$, que exigiría $x^2 + y^2 = 61$ con $xy = 10$. -->
- [ ] D) $5$
  <!-- feedback: Incorrecto. $5^2 = 25$, menor que $29$, imposible con $xy$ positivo. -->
### Explicacion Pedagogica
La identidad clave es $(x + y)^2 = x^2 + 2xy + y^2$. Sustituyendo: $29 + 2(10) = 49$. Como $x + y$ es positivo, $x + y = \sqrt{49} = 7$. Esta técnica evita resolver el sistema completo.
