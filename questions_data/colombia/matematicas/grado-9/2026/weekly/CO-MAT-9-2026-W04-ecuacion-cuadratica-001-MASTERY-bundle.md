**Contexto:** En Bogotá, se estudia la ecuación $2x^2 - 5x + 3 = 0$ escrita en la forma general $ax^2 + bx + c = 0$.
### Enunciado
¿Cuáles son los valores de $a$, $b$ y $c$?
### Opciones
- [ ] A) $a = 2, b = 5, c = 3$
  <!-- feedback: Incorrecto. Olvidaste el signo negativo del término lineal: $b = -5$. -->
- [x] B) $a = 2, b = -5, c = 3$
  <!-- feedback: Correcto. Comparando con $ax^2 + bx + c = 0$ se lee $a = 2$, $b = -5$ y $c = 3$. -->
- [ ] C) $a = 2, b = -5, c = -3$
  <!-- feedback: Incorrecto. El término independiente es $+3$, no $-3$. -->
- [ ] D) $a = 5, b = 2, c = 3$
  <!-- feedback: Incorrecto. Invertiste los coeficientes $a$ y $b$: $a$ acompaña a $x^2$. -->
### Explicacion Pedagogica
En la forma general $ax^2 + bx + c = 0$, el coeficiente $a$ acompaña a $x^2$, $b$ acompaña a $x$ y $c$ es el término independiente. Aquí $a = 2$, $b = -5$ y $c = 3$.
