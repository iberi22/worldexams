**Contexto:** En la clase de matemáticas del Colegio San José de Bogotá, la profesora explica qué es una expresión algebraica.
**Expected_Success:** 0.85

### Enunciado
¿Qué es una expresión algebraica?

### Opciones
- [ ] A) Una operación aritmética que solo usa números. <!-- feedback: Incorrecto. Una expresión algebraica usa números y letras. -->
- [x] B) Una combinación de números, letras (variables) y operaciones matemáticas. <!-- feedback: Correcto. Las letras representan valores desconocidos. -->
- [ ] C) Una ecuación que siempre tiene un signo igual. <!-- feedback: Incorrecto. Una expresión no tiene signo igual; una ecuación sí. -->

### Explicacion Pedagogica
Una expresión algebraica es una combinación de constantes (números), variables (letras como x, y, a, b) y operaciones (+, −, ×, ÷). Por ejemplo: 3x + 5, 2a² − 7b, 4(x + 3). A diferencia de una ecuación, no tiene signo igual (=). Las expresiones algebraicas nos permiten generalizar relaciones matemáticas.

### Enunciado
¿Cuál es la expresión algebraica que representa "el doble de un número aumentado en cinco"?

### Opciones
- [ ] A) 2 + x + 5 <!-- feedback: Incorrecto. "El doble de un número" es 2x, no 2+x. -->

**Contexto:** Laura debe simplificar la expresión 5a + 3b − 2a + b en su clase de Cali.
**Expected_Success:** 0.78

### Enunciado
Al simplificar 5a + 3b − 2a + b, ¿cuál es el resultado?

### Opciones
- [ ] A) 3a + 4b <!-- feedback: Correcto. Se combinan términos semejantes. -->
- [x] B) 7a + 4b <!-- feedback: Incorrecto. 5a − 2a = 3a, no 7a. -->

¿Cuál es la expresión simplificada para el área del rectángulo?

**Expected_Success:** 0.65

### Enunciado
¿Son equivalentes las expresiones 3x + 5 y 5 + 3x?

### Opciones
- [x] A) Sí, porque la suma es conmutativa: el orden de los sumandos no altera la suma. <!-- feedback: Correcto. a + b = b + a. -->
- [ ] B) No, porque el orden de los términos siempre importa. <!-- feedback: Incorrecto. En la suma, el orden no importa. -->
- [ ] C) Sí, pero solo cuando x = 0. <!-- feedback: Incorrecto. Son equivalentes para cualquier valor de x. -->

### Explicacion Pedagogica
Dos expresiones son equivalentes si tienen el mismo valor para cualquier valor de las variables. La propiedad conmutativa de la suma establece que a + b = b + a. Por lo tanto, 3x + 5 y 5 + 3x son equivalentes. Sin embargo, esto no aplica para la resta: 3x − 5 ≠ 5 − 3x.

## Question 10 [D8]
**ID:** `CO-MAT-7-2026-W03-algebra-basica-001-MASTERY-v10`
**Bloom:** Evaluate
**ICFES:** Explicación de fenómenos
**Contexto:** Isabella y su amiga discuten: "¿Es lo mismo x² que 2x?" Su profesor en Neiva les pide que lo resuelvan.
**Expected_Success:** 0.48

### Enunciado
¿Cuál de las siguientes afirmaciones sobre x² y 2x es correcta?

### Opciones
- [ ] A) Son equivalentes para todos los valores de x. <!-- feedback: Incorrecto. Solo son iguales para algunos valores. -->
- [x] B) Son equivalentes solo cuando x = 0 o x = 2. <!-- feedback: Correcto. x² = 2x → x² − 2x = 0 → x(x−2) = 0 → x = 0 o x = 2. -->
- [ ] C) Nunca son equivalentes. <!-- feedback: Incorrecto. Sí lo son para x = 0 y x = 2. -->
- [ ] D) Son equivalentes solo cuando x = 1. <!-- feedback: Incorrecto. 1² = 1, 2(1) = 2, no son iguales. -->

### Explicacion Pedagogica
x² (x al cuadrado) significa x multiplicado por sí mismo: x · x. 2x significa el doble de x: x + x o 2 · x. Son expresiones diferentes. Si resolvemos x² = 2x → x² − 2x = 0 → x(x − 2) = 0 → x = 0 o x = 2. Para cualquier otro valor, x² y 2x son diferentes. Esta distinción es crucial en álgebra.

## Question 12 [D9]
**ID:** `CO-MAT-7-2026-W03-algebra-basica-001-MASTERY-v12`
**Bloom:** Evaluate
**ICFES:** Indagación
**Contexto:** Daniel tiene un rectángulo con área (2x² + 6x) y su profesor en Tunja pregunta si puede factorizarse.
**Expected_Success:** 0.42

### Enunciado
¿Cuál es la factorización de 2x² + 6x?

### Opciones
- [ ] A) 2(x² + 3) <!-- feedback: Incorrecto. Falta la x en el segundo término. -->
- [ ] B) x(2x + 6x) <!-- feedback: Incorrecto. 6x factorizado por x sería 6, no 6x. -->
- [x] C) 2x(x + 3) <!-- feedback: Correcto. Factor común 2x: 2x(x) + 2x(3) = 2x² + 6x. -->
- [ ] D) 2(x² + 6x) <!-- feedback: Incorrecto. 2(x² + 6x) daría 2x² + 12x. -->

### Explicacion Pedagogica
La factorización es el proceso inverso de la propiedad distributiva. Se busca el máximo factor común (MFC) de todos los términos. En 2x² + 6x, el MFC es 2x (porque 2 divide a 2 y 6, y x está en ambos términos). Entonces: 2x² + 6x = 2x(x) + 2x(3) = 2x(x + 3). La factorización es útil para simplificar expresiones y resolver ecuaciones.
