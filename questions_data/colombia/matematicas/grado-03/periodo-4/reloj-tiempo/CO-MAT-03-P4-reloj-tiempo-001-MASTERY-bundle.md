# Bundle Mastery: Lectura del Reloj y Unidades de Tiempo

Este bundle evalúa la capacidad de leer la hora en relojes analógicos y digitales, y comprender las equivalencias entre minutos, horas, días y semanas.

### Enunciado
¿Cuántos **minutos** tiene una hora completa?

### Options
