# Bundle Mastery: Infografías y Tablas

Las infografías y tablas presentan información de forma visual y organizada. Las infografías combinan imágenes, textos cortos y datos. Las tablas organizan datos en filas y columnas. Este bundle explora estos recursos para grado 3 en contexto colombiano.
