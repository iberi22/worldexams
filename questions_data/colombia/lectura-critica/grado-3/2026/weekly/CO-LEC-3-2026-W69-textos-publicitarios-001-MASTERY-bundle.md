# Bundle Mastery: Textos Publicitarios

Los textos publicitarios buscan promover un producto, servicio o idea. Usan lenguaje persuasivo, imágenes llamativas y eslóganes. Este bundle explora la publicidad para grado 3 en contexto colombiano.

## Question 8 [D5]
**ID:** `CO-LEC-3-2026-W69-textos-publicitarios-001-MASTERY-v8`
**Bloom:** Evaluate
**ICFES:** Crítico
**Expected_Success:** 0.48

### Contexto
**Situación:** Un anuncio de televisión dice: "Este cereal tiene más vitaminas que cualquier otro. Si no lo compras, tus hijos no crecerán fuertes."

### Enunciado
¿Qué problema tiene este anuncio?

### Options
- [ ] A) No dice el precio <!-- feedback: No es obligatorio. -->
- [x] B) Exagera ("más que cualquier otro" difícil de probar) y usa miedo ("tus hijos no crecerán fuertes") para manipular <!-- feedback: ¡Correcto! Usa exageración y manipulación emocional. -->
- [ ] C) Es muy largo <!-- feedback: Incorrecto. -->
- [ ] D) No tiene colores llamativos <!-- feedback: Es televisión, puede tener colores. -->

### Explicación Pedagógica
La publicidad a veces usa exageraciones ("el mejor", "el más", "cualquier otro") y manipulaciones emocionales (miedo, culpa) que debemos aprender a identificar para no dejarnos engañar.
