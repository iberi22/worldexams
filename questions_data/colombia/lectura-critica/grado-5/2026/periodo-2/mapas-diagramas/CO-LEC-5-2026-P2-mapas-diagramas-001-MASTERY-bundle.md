# Lectura Crítica G5: El Mapa de los Sueños de la Clase 5B

*La profesora Inés pidió a sus estudiantes de quinto grado de la I.E. San Rafael, en Pereira, que hicieran un mapa conceptual sobre "Los Ecosistemas de Colombia". Cada grupo eligió un ecosistema diferente. El grupo de Camilo, Daniela y Marian hizo un mapa sobre la selva amazónica. Así quedó su mapa conceptual:*

```
            LOS ECOSISTEMAS DE COLOMBIA
                        |
        ┌───────────────┼───────────────┐
        |               |               |
    SELVA           PÁRAMO          OCÉANO
    AMAZÓNICA       ANDINO          CARIBE
        |               |               |
    ┌───┼───┐       ┌───┼───┐       ┌───┼───┐
    |   |   |       |   |   |       |   |   |
 CLIMA  FAUNA  FLORA   CLIMA  FAUNA FLORA  CLIMA FAUNA FLORA
cálido  jaguares  orquídeas  frío   cóndor  frailejón  cálido  tortugas  manglares
húmedo  delfines  ceibas    seco   venado  pajonal    salado  corales  algas
lluvioso  guacamayas  lianas  neblina  oso     musgo    cristalino  peces  pastos
                            andino  líquenes                marinos
```

*Después de hacer el mapa, la profesora pidió que cada grupo escribiera un resumen explicando lo que habían aprendido. Esto escribió el grupo de Camilo:*

*"Colombia tiene muchos ecosistemas diferentes. Nosotros estudiamos la selva amazónica, que tiene clima cálido, húmedo y lluvioso. Allí viven jaguares, delfines rosados y guacamayas. Las plantas más importantes son las orquídeas, las ceibas y las lianas. Aprendimos que la selva amazónica colombiana está en el sur del país, en departamentos como Amazonas, Caquetá y Putumayo. Es el pulmón del mundo porque produce mucho oxígeno."*
