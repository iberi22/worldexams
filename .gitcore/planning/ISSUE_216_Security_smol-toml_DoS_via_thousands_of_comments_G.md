## Security Advisory: GHSA-v3rj-xjv7-4jmq

**Severity:** Medium (CVSS 5.3)
**Package:** smol-toml
**Type:** Denial of Service (Stack Overflow)

### Summary
The library uses recursion internally while parsing to skip over commented lines. A TOML document with thousands of consecutive commented lines causes stack exhaustion and a crash.

### Proof of Concept
```js
require('smol-toml').parse('# comment\n'.repeat(8000) + 'key = "value"')
```

### Impact
Applications parsing arbitrary TOML documents may crash if they receive malicious input.

### Fix
Upgrade to >= 1.6.1 (uses iterative approach instead of recursion)
