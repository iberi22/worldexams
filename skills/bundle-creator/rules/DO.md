# DO - Dominican Republic Bundle Creation Rules

## Official Exam Framework
- **Exam:** Pruebas Nacionales
- **Agency:** MINERD (Ministerio de Educación)
- **Subjects:** Matemática, Lengua Española, Ciencias de la Naturaleza, Ciencias Sociales
- **Grade:** 12 (6º de Secundaria)
- **Reference:** https://www.ministeriodeeducacion.gob.do/

## Curriculum Alignment
Aligned with the Dominican national curriculum and Pruebas Nacionales assessment standards.

## Bundle Directory Structure
```
questions_data/do/
  └── grado-11/
      └── periodo-1/
          └── [subject]/
              └── DO-SUBJ-11-P1-TOPIC-NNN-MASTERY-bundle.md
```

## Language & Cultural Rules
- **Terminology:** Use Caribbean Spanish variants suitable for the Dominican Republic.
- **Currency:** Use Pesos Dominicanos (DOP$).
- **Local Context:** Use names of Dominican cities (Santo Domingo, Santiago) and cultural references (Béisbol, Merengue, Bachata).
- Never reference ICFES or Colombia-specific exam names.
