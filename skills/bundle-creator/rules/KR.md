# KR - South Korea Bundle Creation Rules

## Official Exam Framework
- **Exam:** Suneung (대학수학능력시험 / College Scholastic Ability Test — CSAT)
- **Agency:** Korea Institute for Curriculum and Evaluation (KICE)
- **Subjects:** Korean Language (국어), Mathematics (수학), English (영어), Korean History (한국사), Social Studies/ Science/ Vocational (탐구영역), Second Foreign Language (제2외국어)
- **Grade:** 12th grade (고등학교 3학년)
- **Reference:** https://www.kice.re.kr/ | https://www.suneung.re.kr/

## Language & Cultural Rules
- Use English for questions (primary international language)
- Use KRW ₩ (Won) for currency
- Reference Korean cities: Seoul, Busan, Incheon, Daegu, Daejeon, Gwangju
- Reference Korean cultural, geographic, and historical contexts
- Never reference ICFES or Colombian exam names
