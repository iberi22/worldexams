# EC - Ecuador Bundle Creation Rules

## Official Exam Framework
- **Exam:** Ser Bachiller / SENESCYT
- **Agency:** SENESCYT (Secretaría de Educación Superior, Ciencia, Tecnología e Innovación)
- **Subjects:** Matemática, Lengua y Literatura, Ciencias Naturales, Estudios Sociales
- **Grade:** 12 (3º de Bachillerato)
- **Reference:** https://www.educacionsuperior.gob.ec/

## Curriculum Alignment
Aligned with the national curriculum for Bachillerato General Unificado (BGU).

## Bundle Directory Structure
```
questions_data/ecuador/
  └── grado-11/
      └── periodo-1/
          └── [subject]/
              └── EC-SUBJ-11-P1-TOPIC-NNN-MASTERY-bundle.md
```

## Language & Cultural Rules
- **Terminology:** Use standard Spanish with local Ecuadorian references.
- **Currency:** Use US Dollars (USD $).
- **Local Context:** Use names of Ecuadorian cities (Quito, Guayaquil, Cuenca) and landmarks (Islas Galápagos, Mitad del Mundo).
- Never reference ICFES or Colombia-specific exam names.
