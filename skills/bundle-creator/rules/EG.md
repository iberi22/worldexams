# EG - Egypt Bundle Creation Rules

## Official Exam Framework
- **Exam:** Thanaweya Amma (General Secondary Education Certificate)
- **Agency:** Ministry of Education and Technical Education
- **Subjects:** Arabic, English, Mathematics, Physics, Chemistry, Biology, History, Geography
- **Grade:** 12 (Third Secondary)
- **Reference:** https://moe.gov.eg/

## Curriculum Alignment
Aligned with the Egyptian national curriculum for the General Secondary track.

## Language & Cultural Rules
- **Terminology:** Use standard Arabic (or English for language sections).
- **Currency:** Use Egyptian Pounds (EGP).
- **Local Context:** Use names of Egyptian cities (Cairo, Alexandria, Giza) and landmarks (Pyramids, Nile).
- **Note:** Currently only `matematicas` (Mathematics) is implemented in the repository structure.
- Never reference ICFES or Colombia-specific exam names.
