# EG - Egypt Bundle Creation Rules

## Official Exam Framework
- **Exam:** Thanaweya Amma (الشهادة الثانوية العامة / General Secondary Certificate)
- **Agency:** Ministry of Education and Technical Education
- **Subjects:** Arabic Language, Mathematics, Physics, Chemistry, Biology, History, Geography, Philosophy, Psychology, English, French, German (depending on track)
- **Grade:** 12th grade (3rd year of General Secondary / الثانوية العامة)
- **Reference:** https://www.moe.gov.eg/

## Bundle Directory Structure
```
questions_data/egypt/
  └── grado-11/
      └── periodo-1/
          └── [subject]/
              └── EG-SUBJ-11-P1-TOPIC-NNN-MASTERY-bundle.md
```

## Language & Cultural Rules
- Use English for questions (international language option)
- Use EGP £ (Egyptian Pound) for currency
- Reference Egyptian cities: Cairo, Alexandria, Giza, Luxor, Aswan, Sharm El-Sheikh
- Reference Egyptian cultural, geographic, and historical contexts
- Never reference ICFES or Colombian exam names
