# ID - Indonesia Bundle Creation Rules

## Official Exam Framework
- **Exam:** SNBT (Seleksi Nasional Berdasarkan Tes) / UTBK
- **Agency:** SNPMB (Seleksi Nasional Penerimaan Mahasiswa Baru)
- **Subjects:** Potensi Kognitif, Penalaran Matematika, Literasi Bahasa Indonesia, Literasi Bahasa Inggris
- **Grade:** 12 (Kelas 12)
- **Reference:** https://snpmb.bppp.kemdikbud.go.id/

## Curriculum Alignment
Aligned with the Indonesian "Kurikulum Merdeka" and the SNBT assessment framework.

## Language & Cultural Rules
- **Linguistic Variant:** Use Bahasa Indonesia.
- **Currency:** Use Indonesian Rupiah (IDR Rp).
- **Local Context:** Use names of Indonesian cities (Jakarta, Surabaya, Bandung) and landmarks (Borobudur, Bali).
- **Note:** Currently only `matematicas` (Mathematics) is implemented in the repository structure.
- Never reference ICFES or Colombia-specific exam names.
