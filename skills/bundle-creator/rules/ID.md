# ID - Indonesia Bundle Creation Rules

## Official Exam Framework
- **Exam:** Ujian Nasional (UN) / Asesmen Nasional (AN) — transitioning
- **Agency:** Kemendikbudristek (Kementerian Pendidikan, Kebudayaan, Riset, dan Teknologi)
- **Subjects:** Bahasa Indonesia, Matematika, Bahasa Inggris, IPA (Ilmu Pengetahuan Alam — Fisika, Kimia, Biologi), IPS (Ilmu Pengetahuan Sosial — Geografi, Ekonomi, Sosiologi)
- **Grade:** SMA Kelas 12 (12th grade / Sekolah Menengah Atas)
- **Reference:** https://www.kemdikbud.go.id/

## Bundle Directory Structure

questions_data/indonesia/

## Language & Cultural Rules
- Use Bahasa Indonesia for all questions
- Use IDR Rp (Rupiah) for currency
- Reference Indonesian cities: Jakarta, Surabaya, Bandung, Yogyakarta, Bali
- Reference Indonesian cultural, geographic, and historical contexts
- Never reference ICFES or Colombian exam names
