# AR - Argentina Bundle Creation Rules

## Official Exam Framework
- **Exam:** APRENDER (Evaluación Nacional de Aprendizajes)
- **Agency:** Ministerio de Educación
- **Subjects:** Matemática, Lengua, Ciencias Naturales, Ciencias Sociales
- **Grade:** 11 (Final year of secondary education, often 6º Secundaria)
- **Reference:** https://www.argentina.gob.ar/educacion/evaluacion-informacion-educativa/aprender

## Curriculum Alignment
Aligned with NAP (Núcleos de Aprendizaje Prioritarios) and the Aprender assessment framework.

## Bundle Directory Structure
```
questions_data/argentina/
  └── grado-11/
      └── periodo-1/
          └── [subject]/
              └── AR-SUBJ-11-P1-TOPIC-NNN-MASTERY-bundle.md
```

## Language & Cultural Rules
- **Linguistic Variant:** Strictly use "voseo" (use 'vos', 'tenés', 'hacés' instead of 'tú', 'tienes', 'haces').
- **Currency:** Use Pesos Argentinos (ARS$).
- **Local Context:** Use names of Argentine cities (Buenos Aires, Córdoba, Rosario) and cultural references (tango, asado, mate, fútbol).
- Never reference ICFES or Colombia-specific exam names.
