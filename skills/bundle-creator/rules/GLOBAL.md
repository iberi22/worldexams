# GLOBAL - Global/Generic Bundle Creation Rules

## Purpose
For bundles that are not tied to a specific country or exam framework. These are cross-cultural, general knowledge, or skill-based bundles.

## Scope
- Generic mathematics bundles
- Generic science bundles (astronomy, general biology, etc.)
- Cross-cultural social studies
- CEFR-based language assessment bundles

## Bundle Directory Structure
These bundles live in individual country directories but use generic content. Alternatively, they can use the `global` country code.

## Language & Cultural Rules
- Use culturally neutral references
- Use diverse names from various cultures
- Avoid country-specific exam names (ICFES, ENEM, PAES, etc.)
- Use "global" as country in frontmatter: `country: "global"`
- No currency or geography assumptions
