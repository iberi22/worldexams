# PY - Paraguay Bundle Creation Rules

## Official Exam Framework
- **Exam:** SNEPE / Pruebas Nacionales
- **Agency:** MEC (Ministerio de Educación y Ciencias)
- **Subjects:** Matemática, Lengua y Literatura Castellana, Ciencias de la Naturaleza, Ciencias Sociales
- **Grade:** 11 (2º Curso - Nivel Medio)
- **Reference:** https://www.mec.gov.py/

## Curriculum Alignment
Aligned with the Paraguayan national curriculum and SNEPE assessment standards.

## Bundle Directory Structure
```
questions_data/py/
  └── grado-11/
      └── periodo-1/
          └── [subject]/
              └── PY-SUBJ-11-P1-TOPIC-NNN-MASTERY-bundle.md
```

## Language & Cultural Rules
- **Linguistic Variant:** Use "voseo" (common in Paraguay) and include Guarani cultural references where appropriate.
- **Currency:** Use Guaraníes (₲).
- **Local Context:** Use names of Paraguayan cities (Asunción, Ciudad del Este) and cultural references (Tereré, Ñandutí).
- Never reference ICFES or Colombia-specific exam names. Use **SNEPE:** for competency alignment.
