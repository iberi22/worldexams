# UY - Uruguay Bundle Creation Rules

## Official Exam Framework
- **Exam:** Aristas / PISA / Admisión
- **Agency:** ANEP / UDELAR
- **Subjects:** Matemática, Lengua y Literatura, Ciencias de la Naturaleza, Ciencias Sociales
- **Grade:** 11 (5° Bachillerato)
- **Reference:** https://www.anep.edu.uy/

## Curriculum Alignment
Aligned with the "Marco Curricular Nacional" (MCN) and UDELAR admission standards.

## Bundle Directory Structure
```
questions_data/uy/
  └── grado-11/
      └── periodo-1/
          └── [subject]/
              └── UY-SUBJ-11-P1-TOPIC-NNN-MASTERY-bundle.md
```

## Language & Cultural Rules
- **Linguistic Variant:** Strictly use "voseo" (use 'vos', 'tenés' instead of 'tú', 'tienes').
- **Currency:** Use Pesos Uruguayos ($U).
- **Local Context:** Use names of Uruguayan cities (Montevideo, Salto, Paysandú) and cultural references (Mate, Asado, Candombe).
- Never reference ICFES or Colombia-specific exam names. Use **Aristas:** for competency alignment.
