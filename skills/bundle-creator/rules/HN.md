# HN - Honduras Bundle Creation Rules

## Official Exam Framework
- **Exam:** Pruebas Nacionales
- **Agency:** SEDUC (Secretaría de Educación)
- **Subjects:** Matemáticas, Español, Ciencias Naturales, Estudios Sociales
- **Grade:** 11 (Último año de Media)
- **Reference:** https://www.se.gob.hn/

## Curriculum Alignment
Aligned with the Honduran national curriculum for secondary education.

## Bundle Directory Structure
```
questions_data/hn/
  └── grado-11/
      └── periodo-1/
          └── [subject]/
              └── HN-SUBJ-11-P1-TOPIC-NNN-MASTERY-bundle.md
```

## Language & Cultural Rules
- **Terminology:** Use standard Spanish with local Honduran references.
- **Currency:** Use Lempiras (L).
- **Local Context:** Use names of Honduran cities (Tegucigalpa, San Pedro Sula) and landmarks (Copán Ruinas, Islas de la Bahía).
- Never reference ICFES or Colombia-specific exam names.
