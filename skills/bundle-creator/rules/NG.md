# NG - Nigeria Bundle Creation Rules

## Official Exam Framework
- **Exam:** WAEC SSCE (West African Senior School Certificate Examination) / NECO
- **Agency:** WAEC (West African Examinations Council) / NECO (National Examinations Council)
- **Subjects:** English Language, Mathematics, Physics, Chemistry, Biology, Geography, Economics, Government, Literature in English, Agricultural Science, Commerce, etc.
- **Grade:** SS3 (Senior Secondary 3 / 12th grade)
- **Reference:** https://www.waeconline.org.ng/ | https://www.neco.gov.ng/

## Bundle Directory Structure
```
questions_data/nigeria/
  └── grado-11/
      └── periodo-1/
          └── [subject]/
              └── NG-SUBJ-11-P1-TOPIC-NNN-MASTERY-bundle.md
```

## Language & Cultural Rules
- Use English (official language for WAEC/NECO)
- Use NGN ₦ (Naira) for currency
- Reference Nigerian cities: Lagos, Abuja, Port Harcourt, Ibadan, Kano, Enugu
- Reference Nigerian cultural, geographic, and historical contexts
- Never reference ICFES or Colombian exam names
