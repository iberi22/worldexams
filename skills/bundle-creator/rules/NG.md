# NG - Nigeria Bundle Creation Rules

## Official Exam Framework
- **Exam:** UTME (Unified Tertiary Matriculation Examination) / JAMB
- **Agency:** Joint Admissions and Matriculation Board (JAMB)
- **Subjects:** English, Mathematics, Science, Social Studies
- **Grade:** 12 (Senior Secondary 3)
- **Reference:** https://jamb.gov.ng/

## Curriculum Alignment
Aligned with the NERDC (Nigerian Educational Research and Development Council) curriculum and UTME syllabus.

## Language & Cultural Rules
- **Linguistic Variant:** Use Nigerian English.
- **Currency:** Use Naira (NGN ₦).
- **Local Context:** Use names of Nigerian cities (Lagos, Abuja, Kano) and cultural references (Jollof Rice, Nollywood).
- **Note:** Currently only `matematicas` (Mathematics) is implemented in the repository structure.
- Never reference ICFES or Colombia-specific exam names.
