# BO - Bolivia Bundle Creation Rules

## Official Exam Framework
- **Exam:** OPCE / Bachillerato (Olimpiada Científica Estudiantil Plurinacional Boliviana / Diploma de Bachiller)
- **Agency:** Ministerio de Educación
- **Subjects:** Matemática, Lenguaje, Ciencias Naturales, Ciencias Sociales
- **Grade:** 12 (6º de Secundaria)
- **Reference:** https://www.minedu.gob.bo/

## Curriculum Alignment
Aligned with the "Modelo Educativo Sociocomunitario Productivo" (MESCP) and national Bachillerato requirements.

## Bundle Directory Structure
```
questions_data/bo/
  └── grado-11/
      └── periodo-1/
          └── [subject]/
              └── BO-SUBJ-11-P1-TOPIC-NNN-MASTERY-bundle.md
```

## Language & Cultural Rules
- **Terminology:** Use local terminology and neutral Spanish suitable for Bolivia.
- **Currency:** Use Bolivianos (Bs).
- **Local Context:** Use names of Bolivian cities (La Paz, Santa Cruz, Cochabamba) and landmarks (Salar de Uyuni, Tiahuanaco).
- Never reference ICFES or Colombia-specific exam names.
