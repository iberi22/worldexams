# GQ - Equatorial Guinea Bundle Creation Rules

## Official Exam Framework
- **Exam:** Selectividad (Pruebas de Acceso a la Universidad)
- **Agency:** UNGE (Universidad Nacional de Guinea Ecuatorial)
- **Subjects:** Matemáticas, Lengua Española, Ciencias Naturales
- **Grade:** 12 (2º de Bachillerato)
- **Reference:** https://unge.education/

## Curriculum Alignment
Aligned with the UNGE framework for university admission in Equatorial Guinea.

## Language & Cultural Rules
- **Terminology:** Use standard Spanish as spoken in Equatorial Guinea.
- **Currency:** Use Franco CFA (FCFA / XAF).
- **Local Context:** Use names of Equatoguinean cities (Malabo, Bata) and cultural references (Ceiba, Danza balélé).
- Never reference ICFES or Colombia-specific exam names. Use **UNGE:** for competency alignment.
