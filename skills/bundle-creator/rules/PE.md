# PE - Peru Bundle Creation Rules

## Official Exam Framework
- **Exam:** Admisión Universitaria (UNMSM, UNI, PUCP) / ECE
- **Agency:** MINEDU (Ministerio de Educación)
- **Subjects:** Matemática, Comunicación, Ciencia y Tecnología, Ciencias Sociales
- **Grade:** 11 (Quinto de Secundaria)
- **Reference:** http://www.minedu.gob.pe/

## Curriculum Alignment
Aligned with CNEB 2016 (Currículo Nacional de la Educación Básica) and university admission requirements.

## Bundle Directory Structure
```
questions_data/peru/
  └── grado-11/
      └── periodo-1/
          └── [subject]/
              └── PE-SUBJ-11-P1-TOPIC-NNN-MASTERY-bundle.md
```

## Language & Cultural Rules
- **Terminology:** Strictly avoid "ICFES" or Colombian terms. Use "CNEB", "Competencia", and "Educación Básica Regular".
- **Currency:** Use Soles (S/).
- **Local Context:** Use names of Peruvian cities (Lima, Arequipa, Cusco) and landmarks (Machu Picchu).
- Never reference ICFES or Colombia-specific exam names. Use **Competencia:** for metadata.
