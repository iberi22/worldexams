# GT - Guatemala Bundle Creation Rules

## Official Exam Framework
- **Exam:** Evaluación Nacional de Graduandos
- **Agency:** MINEDUC (Ministerio de Educación)
- **Subjects:** Matemática, Comunicación y Lenguaje, Ciencias Naturales, Ciencias Sociales
- **Grade:** 11 (Ciclo Diversificado)
- **Reference:** https://www.mineduc.gob.gt/

## Curriculum Alignment
Aligned with the National Base Curriculum (CNB) and the Graduandos assessment framework.

## Bundle Directory Structure
```
questions_data/gt/
  └── grado-11/
      └── periodo-1/
          └── [subject]/
              └── GT-SUBJ-11-P1-TOPIC-NNN-MASTERY-bundle.md
```

## Language & Cultural Rules
- **Terminology:** Use Central American Spanish variants suitable for Guatemala.
- **Currency:** Use Quetzales (Q).
- **Local Context:** Use names of Guatemalan cities (Ciudad de Guatemala, Antigua) and cultural references (Tikal, Marimba, Volcanes).
- Never reference ICFES or Colombia-specific exam names.
