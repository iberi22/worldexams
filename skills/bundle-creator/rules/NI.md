# NI - Nicaragua Bundle Creation Rules

## Official Exam Framework
- **Exam:** Exámenes de Bachillerato
- **Agency:** MINED (Ministerio de Educación)
- **Subjects:** Matemáticas, Lengua y Literatura, Ciencias Naturales, Geografía e Historia
- **Grade:** 11 (Undécimo grado)
- **Reference:** https://www.mined.gob.ni/

## Curriculum Alignment
Aligned with the Nicaraguan national curriculum for secondary education.

## Bundle Directory Structure
```
questions_data/ni/
  └── grado-11/
      └── periodo-1/
          └── [subject]/
              └── NI-SUBJ-11-P1-TOPIC-NNN-MASTERY-bundle.md
```

## Language & Cultural Rules
- **Terminology:** Use standard Spanish with local Nicaraguan references.
- **Currency:** Use Córdobas (C$).
- **Local Context:** Use names of Nicaraguan cities (Managua, León, Granada) and cultural references (Rubén Darío, Volcán Masaya).
- Never reference ICFES or Colombia-specific exam names.
