# RU - Russia Bundle Creation Rules

## Official Exam Framework
- **Exam:** EGE (Единый государственный экзамен / Unified State Exam)
- **Agency:** Rosobrnadzor (Federal Service for Supervision in Education and Science)
- **Compulsory Subjects:** Russian Language, Mathematics (Basic or Profile)
- **Elective Subjects:** Physics, Chemistry, Biology, History, Social Studies, Geography, Literature, Foreign Languages (English, German, French, Spanish, Chinese), Informatics and ICT
- **Grade:** 11th grade (Окончание средней школы)
- **Reference:** https://obrnadzor.gov.ru/ | https://ege.edu.ru/

## Language & Cultural Rules
- Use English for questions (international language option)
- Use RUB ₽ (Ruble) for currency
- Reference Russian cities: Moscow, Saint Petersburg, Novosibirsk, Ekaterinburg, Kazan
- Reference Russian cultural, geographic, and historical contexts
- Never reference ICFES or Colombian exam names
