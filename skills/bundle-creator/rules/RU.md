# RU - Russia Bundle Creation Rules

## Official Exam Framework
- **Exam:** Unified State Exam (EGE / ЕГЭ)
- **Agency:** Rosobrnadzor (Federal Service for Supervision in Education and Science)
- **Subjects:** Russian language, Mathematics, Physics, Chemistry, Biology, History
- **Grade:** 11 (Final year of General Secondary Education)
- **Reference:** https://obrnadzor.gov.ru/

## Curriculum Alignment
Aligned with the Federal State Educational Standards (FSES) and EGE assessment framework.

## Bundle Directory Structure
```
questions_data/russia/
  └── matematicas/
      └── grado-9/
          └── algebra/
              └── RU-MAT-09-P1-algebra-NNN-MASTERY-bundle.md
```

## Language & Cultural Rules
- **Linguistic Variant:** Use Russian (Russkiy).
- **Currency:** Use Russian Rubles (RUB ₽).
- **Local Context:** Use names of Russian cities (Moscow, Saint Petersburg, Novosibirsk) and cultural references (Red Square, Hermitage).
- **Note:** Currently only `matematicas` (Mathematics) is implemented in the repository structure.
- Never reference ICFES or Colombia-specific exam names.
