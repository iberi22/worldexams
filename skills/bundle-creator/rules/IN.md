# IN - India Bundle Creation Rules

## Official Exam Framework
- **Exam:** JEE (Joint Entrance Examination) / NEET (National Eligibility cum Entrance Test)
- **Agency:** National Testing Agency (NTA)
- **Subjects:** Mathematics, Physics, Chemistry, Biology, English, Hindi
- **Grade:** 11 (Class 11) / 12 (Class 12)
- **Reference:** https://nta.ac.in/

## Curriculum Alignment
Aligned with the CBSE (Central Board of Secondary Education) curriculum and JEE/NEET syllabi.

## Bundle Directory Structure
```
questions_data/india/
  └── grado-11/
      └── [subject]/
          └── IN-SUBJ-11-P1-TOPIC-NNN-MASTERY-bundle.md
```

## Language & Cultural Rules
- **Linguistic Variant:** Use Indian English or Hindi as specified in the bundle.
- **Currency:** Use Indian Rupees (INR ₹).
- **Local Context:** Use names of Indian cities (Mumbai, Delhi, Bangalore) and cultural references (Cricket, Diwali, Yoga).
- Never reference ICFES or Colombia-specific exam names.
