# CR - Costa Rica Bundle Creation Rules

## Official Exam Framework
- **Exam:** PNE (Pruebas Nacionales Estandarizadas)
- **Agency:** MEP (Ministerio de Educación Pública)
- **Subjects:** Matemáticas, Español, Ciencias, Estudios Sociales, Educación Cívica
- **Grade:** 11 (Undécimo año - Educación Diversificada)
- **Reference:** https://www.mep.go.cr/

## Curriculum Alignment
Aligned with the MEP official study programs and the PNE framework.

## Bundle Directory Structure
```
questions_data/cr/
  └── grado-11/
      └── periodo-1/
          └── [subject]/
              └── CR-SUBJ-11-P1-TOPIC-NNN-MASTERY-bundle.md
```

## Language & Cultural Rules
- **Terminology:** Use local Costa Rican expressions where appropriate (e.g., "Pura Vida" in context).
- **Currency:** Use Colones (₡).
- **Local Context:** Use names of Costa Rican cities (San José, Alajuela, Cartago) and landmarks (Volcán Arenal).
- Never reference ICFES or Colombia-specific exam names.
