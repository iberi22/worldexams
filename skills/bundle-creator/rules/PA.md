# PA - Panamá Bundle Creation Rules

## Official Exam Framework
- **Exam:** Pruebas Nacionales CRECER y de Graduandos
- **Agency:** MEDUCA (Ministerio de Educación)
- **Subjects:**
  - Español (globalId: language) -> Code: ESP
  - Matemáticas (globalId: math) -> Code: MAT
  - Ciencias (globalId: science) -> Code: CIE
  - Ciencias Sociales (globalId: social) -> Code: SOC
  - Inglés (globalId: english) -> Code: ING
- **Grade:** 11 (Bachillerato / Educación Media)
- **Reference:** https://www.meduca.gob.pa/

## Curriculum Alignment
- Align with MEDUCA standards for Educación Media.
- Focus on competency-based evaluation.

## Bundle Directory Structure
```
questions_data/pa/grado-11/periodo-1/[subject]/
  └── PA-CODE-11-P1-TOPIC-NNN-MASTERY-bundle.md
```

## Language & Cultural Rules
- **Currency:** Balboas / Dólares (Use "$" or "balboas"). 1 Balboa = 1 USD.
- **Cities:** Ciudad de Panamá, Colón, David, La Chorrera, Santiago, Penonomé, Chitré.
- **Provinces:** Panamá, Colón, Chiriquí, Coclé, Herrera, Los Santos, Veraguas, Bocas del Toro, Darién, Panamá Oeste.
- **Cultural References:** Canal de Panamá, Puente de las Américas, Esclusas de Miraflores, Casco Antiguo, Pollera (traje típico), Tamborito, Sancocho panameño, Ferrocarril de Panamá.
- **Terminology:** Use local Spanish (Panamanian). Avoid ICFES or Colombian references.
- **Subject Codes:** MAT (Matemáticas), ESP (Español), CIE (Ciencias), SOC (Sociales), ING (Inglés).

## Metadata Alignment
- **Competencia:** Use MEDUCA-aligned competencies (e.g., Razonamiento Matemático, Comprensión Lectora, Pensamiento Científico).
- **ID Prefix:** PA-
