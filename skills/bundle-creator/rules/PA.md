# PA - Panama Bundle Creation Rules

## Official Exam Framework
- **Exam:** CRECER / Graduandos
- **Agency:** MEDUCA (Ministerio de Educación)
- **Subjects:** Matemáticas, Español, Ciencias, Ciencias Sociales
- **Grade:** 12 (Duodécimo grado)
- **Reference:** https://www.meduca.gob.pa/

## Curriculum Alignment
Aligned with the MEDUCA framework and the "Prueba de Graduandos" assessment.

## Bundle Directory Structure
```
questions_data/pa/
  └── grado-11/
      └── periodo-1/
          └── [subject]/
              └── PA-SUBJ-11-P1-TOPIC-NNN-MASTERY-bundle.md
```

## Language & Cultural Rules
- **Terminology:** Use Panamanian Spanish terminology.
- **Currency:** Use Balboas / US Dollars (USD $).
- **Local Context:** Use names of Panamanian provinces (Chiriquí, Colón) and landmarks (Canal de Panamá, Puente de las Américas).
- Never reference ICFES or Colombia-specific exam names.
