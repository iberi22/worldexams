# SV - El Salvador Bundle Creation Rules

## Official Exam Framework
- **Exam:** AVANZO
- **Agency:** MINED (Ministerio de Educación)
- **Subjects:** Matemática, Lenguaje y Literatura, Ciencias Naturales, Estudios Sociales y Cívica
- **Grade:** 11 (Segundo año de Bachillerato)
- **Reference:** https://www.mined.gob.sv/

## Curriculum Alignment
Aligned with the official study programs for Bachillerato in El Salvador.

## Bundle Directory Structure
```
questions_data/sv/
  └── grado-11/
      └── periodo-1/
```

## Language & Cultural Rules
- **Terminology:** Use local Salvadoran references.
- **Currency:** Use US Dollars (USD $) / Bitcoin.
- **Local Context:** Use names of Salvadoran cities (San Salvador, Santa Ana) and cultural references (Pupusas, Volcán de Izalco).
- Never reference ICFES or Colombia-specific exam names.
