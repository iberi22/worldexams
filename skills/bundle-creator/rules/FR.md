# FR - France Bundle Creation Rules

## Official Exam Framework
- **Exam:** Baccalauréat (Général, Technologique, Professionnel)
- **Agency:** Ministère de l'Éducation nationale
- **Subjects:** French, Philosophy, History-Geography, Languages, Mathematics, Sciences
- **Grade:** 12 (Terminale)
- **Reference:** https://www.education.gouv.fr/

## Curriculum Alignment
Aligned with the French national curriculum and the "Plan d'études" for the Lycée.

## Language & Cultural Rules
- **Linguistic Variant:** Use standard French (Français).
- **Currency:** Use Euros (€).
- **Local Context:** Use names of French cities (Paris, Marseille, Lyon) and cultural references (Tour Eiffel, Louvre).
- **Note:** Currently only `matematicas` (Mathematics) is implemented in the repository structure.
- Never reference ICFES or Colombia-specific exam names.
