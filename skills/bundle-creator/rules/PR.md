# PR - Puerto Rico Bundle Creation Rules

## Official Exam Framework
- **Exam:** PAA (Prueba de Aptitud Académica)
- **Agency:** College Board
- **Subjects:** Matemáticas, Lectura y Redacción, Inglés
- **Grade:** 12 (Duodécimo grado)
- **Reference:** https://latam.collegeboard.org/paa/

## Curriculum Alignment
Aligned with the PAA framework used by the University of Puerto Rico (UPR) and other institutions.

## Bundle Directory Structure
```
questions_data/pr/
  └── grado-11/
      └── periodo-1/
          └── [subject]/
              └── PR-SUBJ-11-P1-TOPIC-NNN-MASTERY-bundle.md
```

## Language & Cultural Rules
- **Terminology:** Use Puerto Rican Spanish terminology.
- **Currency:** Use US Dollars (USD $).
- **Local Context:** Use names of Puerto Rican cities (San Juan, Ponce, Mayagüez) and cultural references (Mofongo, Coquí, El Yunque).
- Never reference ICFES or Colombia-specific exam names. Use **PAA:** for competency alignment.
