# JP - Japan Bundle Creation Rules

## Official Exam Framework
- **Exam:** Daigaku Nyushi Center Shiken / Kyotsu Test (Common Test for University Admissions)
- **Agency:** National Center for University Entrance Examinations (Daigaku Nyushi Center) / MEXT (Ministry of Education, Culture, Sports, Science and Technology)
- **Subjects:** Japanese Language, Geography & History, Civics, Mathematics, Science, Foreign Languages (English)
- **Grade:** 12th grade (Kōtōgakkō 3rd year / 高等学校3年)
- **Reference:** https://www.dnc.ac.jp/ | https://www.mext.go.jp/

## Language & Cultural Rules
- Use English for questions (primary language for international students)
- Use JPY ¥ (Yen) for currency
- Reference Japanese cities: Tokyo, Osaka, Kyoto, Yokohama, Nagoya, Sapporo
- Reference Japanese cultural, geographic, and historical contexts
- Never reference ICFES or Colombian exam names
