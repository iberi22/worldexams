# 문제

서울의 한 카페에서 아메리카노 한 잔의 가격은 ₩4,500이고 카페라떼 한 잔의 가격은 ₩5,500입니다. 지현이가 아메리카노 3잔과 카페라떼 2잔을 주문했다면, 총 얼마를 지불해야 합니까?

# 선택지

- [ ] A) ₩22,000
- [ ] B) ₩23,000
- [x] C) ₩24,500
- [ ] D) ₩26,000

# 설명

이 문제를 풀기 위해:

1. **아메리카노 비용 계산**: 3잔 × ₩4,500 = ₩13,500
2. **카페라떼 비용 계산**: 2잔 × ₩5,500 = ₩11,000
3. **총 비용 합계**: ₩13,500 + ₩11,000 = **₩24,500**

정답은 **C) ₩24,500**입니다.

**다른 선택지가 틀린 이유:**
- A) ₩22,000: 3 × 4,000 + 2 × 5,000으로 잘못 계산
- B) ₩23,000: 계산 오류
- D) ₩26,000: 3 × 5,500 + 2 × 4,500으로 잘못 계산
