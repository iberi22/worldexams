# Pregunta Base: Concepto de Función y Representaciones

> **Contexto:** Una función es una relación entre dos conjuntos donde a cada elemento del dominio le corresponde exactamente un elemento del codominio.

---

## Pregunta 1 (Muy Fácil A - Dificultad 1)
**ID:** "CO-MAT-10-funciones-001-v1"

### Enunciado
En la función $f(x) = x + 3$, ¿cuál es el valor de $f(2)$?

### Opciones
- [x] A) 5
- [ ] B) 3
- [ ] C) 2
- [ ] D) 6

### Explicación Pedagógica
$f(2) = 2 + 3 = 5$. Sustituimos $x$ por 2 en la fórmula.

## Pregunta 2 (Muy Fácil B - Dificultad 1)
**ID:** "CO-MAT-10-funciones-001-v2"

### Enunciado
¿Cuál de estas relaciones NO es una función?

### Opciones
- [ ] A) A cada estudiante le corresponde su número de cédula
- [ ] B) A cada país le corresponde su capital
- [x] C) A cada persona le corresponden sus profesores
- [ ] D) A cada ciudad le corresponde su alcalde

### Explicación Pedagógica
Una persona puede tener varios profesores, violando la condición de que a cada elemento del dominio le corresponda UN solo elemento.

## Pregunta 3 (Fácil A - Dificultad 2)
**ID:** "CO-MAT-10-funciones-001-v3"

### Enunciado
Si $f(x) = 2x - 1$, ¿cuál es el valor de $f(0)$?

### Opciones
- [x] A) -1
- [ ] B) 0
- [ ] C) 1
- [ ] D) 2

### Explicación Pedagógica
$f(0) = 2(0) - 1 = 0 - 1 = -1$.

## Pregunta 4 (Fácil B - Dificultad 2)
**ID:** "CO-MAT-10-funciones-001-v4"

### Enunciado
El dominio de la función $f(x) = \sqrt{x}$ es:

### Opciones
- [ ] A) Todos los números reales
- [x] B) Los números reales mayores o iguales a cero
- [ ] C) Solo los números positivos
- [ ] D) Los números enteros

### Explicación Pedagógica
La raíz cuadrada solo está definida para números no negativos, por lo que el dominio es $x ≥ 0$.

## Pregunta 5 (Media A - Dificultad 3)
**ID:** "CO-MAT-10-funciones-001-v5"

### Enunciado
Si $f(x) = x^2$, ¿cuál es $f(-3)$?

### Opciones
- [ ] A) -9
- [ ] B) -6
- [x] C) 9
- [ ] D) 6

### Explicación Pedagógica
$f(-3) = (-3)^2 = 9$. El cuadrado de cualquier número es siempre positivo.

## Pregunta 6 (Media B - Dificultad 3)
**ID:** "CO-MAT-10-funciones-001-v6"

### Enunciado
Una empresa de transporte en Medellín cobra $2.000 de base más $500 por kilómetro. La función que representa el costo $C$ en términos de kilómetros $k$ es:

### Opciones
- [x] A) $C(k) = 2000 + 500k$
- [ ] B) $C(k) = 500 + 2000k$
- [ ] C) $C(k) = 2500k$
- [ ] D) $C(k) = 2000k + 500$

### Explicación Pedagógica
El costo fijo ($2.000) más el costo variable ($500 × kilómetros) da $C(k) = 2000 + 500k$.

## Pregunta 7 (Difícil A - Dificultad 4)
**ID:** "CO-MAT-10-funciones-001-v7"

### Enunciado
Si $f(x) = 3x + 2$ y $g(x) = x - 1$, ¿cuál es $(f \circ g)(2)$?

### Opciones
- [ ] A) 3
- [x] B) 5
- [ ] C) 7
- [ ] D) 8

### Explicación Pedagógica
$(f \circ g)(2) = f(g(2))$. Primero $g(2) = 2 - 1 = 1$. Luego $f(1) = 3(1) + 2 = 5$.

## Pregunta 8 (Difícil B - Dificultad 4)
**ID:** "CO-MAT-10-funciones-001-v8"

### Enunciado
¿Cuál es la función inversa de $f(x) = 2x + 4$?

### Opciones
- [ ] A) $f^{-1}(x) = 2x - 4$
- [x] B) $f^{-1}(x) = \frac{x - 4}{2}$
- [ ] C) $f^{-1}(x) = \frac{x + 4}{2}$
- [ ] D) $f^{-1}(x) = \frac{2}{x + 4}$

### Explicación Pedagógica
Para hallar la inversa: $y = 2x + 4$, despejamos $x$: $x = \frac{y - 4}{2}$. Intercambiamos: $f^{-1}(x) = \frac{x - 4}{2}$.

## Pregunta 9 (Muy Difícil A - Dificultad 5)
**ID:** "CO-MAT-10-funciones-001-v9"

### Enunciado
La función $f(x) = |x|$ es:

### Opciones
- [ ] A) Creciente en todo su dominio
- [ ] B) Decreciente en todo su dominio
- [x] C) Decreciente para $x < 0$ y creciente para $x > 0$
- [ ] D) Constante

### Explicación Pedagógica
El valor absoluto forma una "V": decrece cuando $x$ se acerca a 0 desde la izquierda y crece cuando $x$ se aleja de 0 hacia la derecha.

## Pregunta 10 (Muy Difícil B - Dificultad 5)
**ID:** "CO-MAT-10-funciones-001-v10"

### Enunciado
Si $f(x) = x^2 - 4$ y $g(x) = \sqrt{x + 4}$, ¿cuál es el valor de $(g \circ f)(0)$?

### Opciones
- [ ] A) 4
- [x] B) 0
- [ ] C) 2
- [ ] D) Indefinido

### Explicación Pedagógica
$(g \circ f)(0) = g(f(0))$. $f(0) = 0 - 4 = -4$. $g(-4) = \sqrt{-4 + 4} = \sqrt{0} = 0$.
