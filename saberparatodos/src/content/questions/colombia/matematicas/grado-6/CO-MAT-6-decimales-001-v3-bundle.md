# Pregunta Base: Operaciones con Números Decimales

> **Contexto:** Los decimales son esenciales en situaciones cotidianas como precios, mediciones y porcentajes.

---

## Pregunta 1 (Muy Fácil A - Dificultad 1)
**ID:** "CO-MAT-6-decimales-001-v1"

### Enunciado
¿Cuánto es 2.5 + 1.5?

### Opciones
- [ ] A) 3.0
- [x] B) 4.0
- [ ] C) 3.5
- [ ] D) 4.5

### Explicación Pedagógica
Sumamos: 2.5 + 1.5 = 4.0

## Pregunta 2 (Muy Fácil B - Dificultad 1)
**ID:** "CO-MAT-6-decimales-001-v2"

### Enunciado
¿Qué número es mayor: 3.45 o 3.5?

### Opciones
- [ ] A) 3.45
- [x] B) 3.5
- [ ] C) Son iguales
- [ ] D) No se puede saber

### Explicación Pedagógica
3.5 = 3.50, que es mayor que 3.45 (comparamos 50 centésimas vs 45 centésimas).

## Pregunta 10 (Muy Difícil B - Dificultad 5)
**ID:** "CO-MAT-6-decimales-001-v10"

### Enunciado
El promedio de las notas 3.5, 4.0 y 4.5 es:

### Opciones
- [ ] A) 3.5
- [x] B) 4.0
- [ ] C) 4.5
- [ ] D) 12.0

### Explicación Pedagógica
Promedio = (3.5 + 4.0 + 4.5) ÷ 3 = 12.0 ÷ 3 = 4.0
