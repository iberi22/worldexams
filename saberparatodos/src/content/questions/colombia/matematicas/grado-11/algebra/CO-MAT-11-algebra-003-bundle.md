## Pregunta 1 (Original - Dificultad 3)
**ID:** "CO-MAT-11-algebra-003-v1"
### Enunciado
Factoriza: x² - 9
### Opciones
- [x] A) (x + 3)(x - 3)
- [ ] B) (x - 9)(x + 1)
- [ ] C) (x + 9)(x - 1)
- [ ] D) x(x - 9)
### Explicación Pedagógica
**Respuesta Correcta: A**
Diferencia de cuadrados: a² - b² = (a+b)(a-b)

## Pregunta 7 (Difícil B - Dificultad 5)
**ID:** "CO-MAT-11-algebra-003-v7"
### Enunciado
En Medellín, el área de un rectángulo es x² + 8x + 15. Si se factoriza, ¿cuáles son las dimensiones?
### Opciones
- [x] A) (x + 3) y (x + 5)
- [ ] B) (x + 15) y (x + 1)
- [ ] C) (x + 8) y (x + 15)
- [ ] D) x y (x + 8)
### Explicación Pedagógica
**Respuesta Correcta: A**
x² + 8x + 15 = (x + 3)(x + 5)
