# Pregunta Base: Sistemas de Ecuaciones Lineales

> **Contexto:** Los sistemas de ecuaciones permiten encontrar valores comunes para múltiples condiciones simultáneas.

## Pregunta 1 (Muy Fácil A - Dificultad 1)
**ID:** "CO-MAT-11-ALG-002-v1"

### Enunciado
¿Cuál es el valor de $(x, y)$ que satisface el sistema trivial $x = 5$ e $y = 10$?

### Opciones
- [x] A) (5, 10)
- [ ] B) (10, 5)
- [ ] C) (5, 5)
- [ ] D) (0, 0)

### Explicación Pedagógica
Las ecuaciones dan la solución directa por inspección.

## Pregunta 2 (Muy Fácil B - Dificultad 1)
**ID:** "CO-MAT-11-ALG-002-v2"

### Enunciado
En un sistema, si $x + y = 20$ y $x = y$, ¿cuánto vale $x$?

### Opciones
- [ ] A) 5
- [x] B) 10
- [ ] C) 20
- [ ] D) 0

### Explicación Pedagógica
Si $x = y$, sustituimos: $x + x = 20 \Rightarrow 2x = 20 \Rightarrow x = 10$.

## Pregunta 3 (Fácil A - Dificultad 2)
**ID:** "CO-MAT-11-ALG-002-v3"

### Enunciado
Para el sistema $x + y = 10$ y $x - y = 2$, ¿cuál es el valor de $x$?

### Opciones
- [ ] A) 4
- [x] B) 6
- [ ] C) 8
- [ ] D) 12

### Explicación Pedagógica
Sumamos ambas ecuaciones: $(x+y) + (x-y) = 10 + 2 \Rightarrow 2x = 12 \Rightarrow x = 6$.

## Pregunta 4 (Fácil B - Dificultad 2)
**ID:** "CO-MAT-11-ALG-002-v4"

### Enunciado
Resuelve por sustitución: $y = 2x$ y $x + y = 15$. ¿Cuánto vale $x$?

### Opciones
- [x] A) 5
- [ ] B) 10
- [ ] C) 7.5
- [ ] D) 3

### Explicación Pedagógica
Sustituyendo $y$: $x + (2x) = 15 \Rightarrow 3x = 15 \Rightarrow x = 5$.

## Pregunta 5 (Media A - Dificultad 3)
**ID:** "CO-MAT-11-ALG-002-v5"

### Enunciado
Un parqueadero cobra $2.000 por moto y $5.000 por carro. Si hay 40 vehículos y se recaudaron $110.000, ¿cuántos carros hay?

### Opciones
- [x] A) 10
- [ ] B) 15
- [ ] C) 20
- [ ] D) 30

### Explicación Pedagógica
$m + c = 40 \Rightarrow m = 40 - c$.
$2000m + 5000c = 110000$.
$2000(40-c) + 5000c = 110000 \Rightarrow 80000 - 2000c + 5000c = 110000$.
$3000c = 30000 \Rightarrow c = 10$.

## Pregunta 7 (Difícil A - Dificultad 4)
**ID:** "CO-MAT-11-ALG-002-v7"

### Enunciado
Resuelve el sistema por reducción: $2x + 3y = 12$ y $3x - 2y = 5$. ¿Cuál es el valor de $x$?

### Opciones
- [x] A) 3
- [ ] B) 2
- [ ] C) 1
- [ ] D) 4

### Explicación Pedagógica
Multiplicamos (1) por 2 y (2) por 3:
1. $4x + 6y = 24$
2. $9x - 6y = 15$
Sumando: $13x = 39 \Rightarrow x = 3$.

## Pregunta 8 (Difícil B - Dificultad 4)
**ID:** "CO-MAT-11-ALG-002-v8"

### Enunciado
Dos números suman 45 y su diferencia es 15. ¿Cuál es el producto de los números?

### Opciones
- [ ] A) 300
- [x] B) 450
- [ ] C) 500
- [ ] D) 675

### Explicación Pedagógica
$x+y=45$ e $x-y=15$.
$2x = 60 \Rightarrow x = 30$.
$30 + y = 45 \Rightarrow y = 15$.
Producto: $30 \times 15 = 450$.

## Pregunta 9 (Muy Difícil A - Dificultad 5)
**ID:** "CO-MAT-11-ALG-002-v9"

### Enunciado
Un sistema de ecuaciones es "Inconsistente" si sus gráficas son:

### Opciones
- [ ] A) Rectas que se cortan en un punto.
- [x] B) Rectas paralelas que no se tocan.
- [ ] C) La misma recta (rectas coincidentes).
- [ ] D) Rectas perpendiculares.

### Explicación Pedagógica
Un sistema inconsistente no tiene solución, lo cual gráficamente ocurre cuando las rectas son paralelas pero distintas.

## Pregunta 10 (Muy Difícil B - Dificultad 5)
**ID:** "CO-MAT-11-ALG-002-v10"

### Enunciado
¿Para qué valor de $k$ el sistema $2x + 3y = 5$ y $4x + ky = 10$ tiene infinitas soluciones?

### Opciones
- [ ] A) 3
- [ ] B) 4
- [x] C) 6
- [ ] D) 8

### Explicación Pedagógica
Para tener infinitas soluciones, las ecuaciones deben ser proporcionales.
Comparando coeficientes: $4/2 = k/3 = 10/5$.
$2 = k/3 \Rightarrow k = 6$.
