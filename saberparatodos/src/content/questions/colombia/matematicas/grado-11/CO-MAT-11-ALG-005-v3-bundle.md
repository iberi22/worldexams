## Pregunta 1 (Muy Fácil A - Dificultad 1)
**ID:** "CO-MAT-11-ALG-005-v1"

### Enunciado
¿Cuál es el grado del polinomio $P(x) = 4x^3 - 2x^2 + 5x - 8$?

### Opciones
- [ ] A) 4
- [x] B) 3
- [ ] C) 2
- [ ] D) 1

### Explicación Pedagógica
El grado absoluto de un polinomio en una variable es el mayor exponente. Aquí es 3.

## Pregunta 3 (Fácil A - Dificultad 2)
**ID:** "CO-MAT-11-ALG-005-v3"

### Enunciado
Realiza la suma de polinomios: $(2x^2 + 3) + (x^2 - 1)$.

### Opciones
- [ ] A) $3x^4 + 2$
- [x] B) $3x^2 + 2$
- [ ] C) $2x^2 + 2$
- [ ] D) $3x^2 - 4$

### Explicación Pedagógica
Agrupamos términos semejantes: $(2x^2 + x^2) + (3 - 1) = 3x^2 + 2$.

### Enunciado
Multiplica los monomios: $(3x^2)(2x^3)$.

### Opciones

- [x] B) $6x^5$

## Pregunta 5 (Media A - Dificultad 3)
**ID:** "CO-MAT-11-ALG-005-v5"

### Enunciado
Desarrolla el binomio al cuadrado: $(x + 5)^2$.

### Opciones
- [ ] A) $x^2 + 25$
- [x] B) $x^2 + 10x + 25$
- [ ] C) $x^2 + 5x + 25$
- [ ] D) $x^2 + 10x + 5$

### Explicación Pedagógica
Producto notable: $(a+b)^2 = a^2 + 2ab + b^2$.
$(x)^2 + 2(x)(5) + 5^2 = x^2 + 10x + 25$.

## Pregunta 6 (Media B - Dificultad 3)
**ID:** "CO-MAT-11-ALG-005-v6"

### Enunciado
Factoriza el trinomio cuadrado perfecto: $x^2 - 6x + 9$.

### Opciones
- [ ] A) $(x+3)(x-3)$
- [x] B) $(x-3)^2$
- [ ] C) $(x+3)^2$
- [ ] D) $(x-9)(x+1)$

### Explicación Pedagógica
$\sqrt{x^2} = x, \sqrt{9} = 3$. Doble producto $2(3)(x) = 6x$. Signo negativo.
$(x-3)^2$.

## Pregunta 7 (Difícil A - Dificultad 4)
**ID:** "CO-MAT-11-ALG-005-v7"

### Enunciado
Divide $(x^3 - 8)$ entre $(x - 2)$.

### Opciones
- [x] A) $x^2 + 2x + 4$
- [ ] B) $x^2 - 2x + 4$
- [ ] C) $x^2 + 4$
- [ ] D) $x^2 - 4$

### Explicación Pedagógica
Diferencia de cubos: $a^3 - b^3 = (a-b)(a^2 + ab + b^2)$.
$(x^3 - 2^3) = (x-2)(x^2 + 2x + 4)$.
Al dividir por $(x-2)$, queda $x^2 + 2x + 4$.

## Pregunta 8 (Difícil B - Dificultad 4)
**ID:** "CO-MAT-11-ALG-005-v8"

### Enunciado
Calcula el valor numérico de $P(x) = 2x^3 - x^2 + 1$ para $x = -2$.

### Opciones
- [ ] A) -11
- [x] B) -19
- [ ] C) -15
- [ ] D) 13

### Explicación Pedagógica
$P(-2) = 2(-2)^3 - (-2)^2 + 1 = 2(-8) - (4) + 1 = -16 - 4 + 1 = -19$.

## Pregunta 9 (Muy Difícil A - Dificultad 5)
**ID:** "CO-MAT-11-ALG-005-v9"

### Enunciado
¿Cuál es el residuo de dividir $x^{100} + 5$ entre $x - 1$ usando el Teorema del Residuo?

### Opciones
- [ ] A) 1
- [ ] B) 5
- [x] C) 6
- [ ] D) 0

### Explicación Pedagógica
El residuo es $P(1)$.
$P(1) = 1^{100} + 5 = 1 + 5 = 6$.

## Pregunta 10 (Muy Difícil B - Dificultad 5)
**ID:** "CO-MAT-11-ALG-005-v10"

### Enunciado
Factoriza completamente: $x^4 - 16$.

### Opciones
- [ ] A) $(x^2-4)(x^2+4)$
- [x] B) $(x-2)(x+2)(x^2+4)$
- [ ] C) $(x-2)^2(x+2)^2$
- [ ] D) $(x-2)(x+2)(x-2)(x+2)$

### Explicación Pedagógica
Diferencia de cuadrados: $(x^2 - 4)(x^2 + 4)$.
Luego $(x^2 - 4)$ es otra diferencia: $(x-2)(x+2)(x^2+4)$.
