# Pregunta Base: El Jefe del Computador

> **Contexto:** El Sistema Operativo (SO) es el software más importante. Administra los recursos (memoria, disco, procesador) y permite interactuar con el usuario.

**ID:** "CO-TEC-7-sistema-operativo-001-v1"

### Enunciado
¿Cuál es el Sistema Operativo más usado en computadores personales (PC)?

### Opciones
- [ ] A) Word
- [x] B) Microsoft Windows
- [ ] C) Google
- [ ] D) Facebook

### Explicación Pedagógica
Windows domina el mercado de PCs, aunque existen otros como macOS y Linux.
