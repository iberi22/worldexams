> **Contexto:** Las hojas de cálculo (como Excel o Google Sheets) nos permiten organizar datos, hacer cuentas y crear gráficos.

### Opciones
- [ ] A) Word
- [ ] B) PowerPoint
- [x] C) Excel
- [ ] D) Paint

### Explicación Pedagógica
Excel de Microsoft es el estándar mundial para hojas de cálculo.

### Opciones
- [x] A) Letras (A, B, C...)

- [ ] C) Colores
