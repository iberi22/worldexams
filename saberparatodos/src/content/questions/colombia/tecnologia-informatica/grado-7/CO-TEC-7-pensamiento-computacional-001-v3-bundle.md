# Pregunta Base: Pensando como un Computador

> **Contexto:** El pensamiento computacional es una habilidad para resolver problemas usando lógica, descomposición y patrones.

---

## Pregunta 1 (Muy Fácil A - Dificultad 1)
**ID:** "CO-TEC-7-pensamiento-computacional-001-v1"

### Enunciado
¿Qué es la "Descomposición" de un problema?

### Opciones
- [ ] A) Dejar que se pudra
- [x] B) Dividir un problema grande y difícil en partes más pequeñas y fáciles de resolver
- [ ] C) Romper el computador
- [ ] D) Rendirse

### Explicación Pedagógica
Es más fácil "armar la llanta", "pintar la puerta", etc., que "construir un carro" todo de una vez.

## Pregunta 2 (Muy Fácil B - Dificultad 1)
**ID:** "CO-TEC-7-pensamiento-computacional-001-v2"

### Enunciado
Los "Patrones" nos ayudan a:

### Opciones
- [x] A) Encontrar similitudes o cosas que se repiten para resolver problemas más rápido
- [ ] B) Decorar la ropa
- [ ] C) Gastar tiempo
- [ ] D) Confundirnos

### Explicación Pedagógica
Si sabes cómo resolver un laberinto, puedes aplicar esa misma lógica (patrón) a otros laberintos parecidos.

## Pregunta 3 (Fácil A - Dificultad 2)
**ID:** "CO-TEC-7-pensamiento-computacional-001-v3"

### Enunciado
La "Abstracción" consiste en:

### Opciones
- [ ] A) Dibujar abstracto
- [x] B) Centrarse en la información importante e ignorar los detalles irrelevantes
- [ ] C) No pensar en nada
- [ ] D) Dormir

### Explicación Pedagógica
Para hacer un mapa del metro, no necesitas dibujar los árboles de la calle. Solo importan las estaciones y líneas (abstracción).

### Enunciado
Un "Algoritmo" debe ser:

### Opciones
- [ ] A) Confuso y desordenado
- [x] B) Claro, ordenado, preciso y finito (tiene fin)
- [ ] C) Infinito
- [ ] D) Secreto

### Explicación Pedagógica
Son instrucciones que cualquier persona (o máquina) puede seguir sin dudas para lograr el objetivo.

## Pregunta 5 (Media A - Dificultad 3)
**ID:** "CO-TEC-7-pensamiento-computacional-001-v5"

### Enunciado
En programación, un "Condicional" (IF/ELSE) sirve para:

### Opciones
- [ ] A) Repetir cosas
- [x] B) Tomar decisiones basadas en si algo es verdadero o falso
- [ ] C) Sumar números
- [ ] D) Guardar datos

### Explicación Pedagógica
"SI llueve... ENTONCES llevo sombrilla. SI NO (ELSE)... llevo gafas de sol."

## Pregunta 6 (Media B - Dificultad 3)
**ID:** "CO-TEC-7-pensamiento-computacional-001-v6"

### Enunciado
¿Qué es un "Bucle" (Loop) o Repetición?

### Opciones
- [x] A) Ejecutar el mismo bloque de instrucciones varias veces
- [ ] B) Un nudo en el cable
- [ ] C) Un error
- [ ] D) El final del programa

### Explicación Pedagógica
En lugar de escribir "Caminar" 100 veces, escribes "Repetir 100 veces: Caminar".

### Enunciado
El "Sistema Binario" (0 y 1) es el lenguaje de las máquinas porque:

### Opciones
- [ ] A) A los computadores les gusta el número 1
- [ ] B) Es más difícil
- [x] C) Los circuitos electrónicos solo tienen dos estados: Encendido (1) y Apagado (0)

## Pregunta 9 (Muy Difícil A - Dificultad 5)
**ID:** "CO-TEC-7-pensamiento-computacional-001-v9"

### Enunciado
¿Qué significa "Generalizar" una solución?

### Opciones
- [ ] A) Que no sirva para nada
- [x] B) Adaptar una solución que funcionó en un caso específico para que sirva en muchos casos similares
- [ ] C) Hacerla más difícil
- [ ] D) Esconderla

### Explicación Pedagógica
Si tienes un algoritmo para calcular el área de un cuadrado de 2x2, lo generalizas para calcular el área de CUALQUIER cuadrado (Lado x Lado).
