# Pregunta Base: El Hardware

> **Contexto:** El computador tiene partes físicas que podemos tocar, llamadas Hardware.

---

## Pregunta 1 (Muy Fácil A - Dificultad 1)
**ID:** "CO-TEC-3-partes-computador-001-v1"

### Enunciado
¿Qué parte del computador usas para ver las imágenes y lo que escribes?

### Opciones
- [ ] A) El ratón
- [x] B) La pantalla (Monitor)
- [ ] C) El teclado
- [ ] D) Los parlantes

### Explicación Pedagógica
El monitor o pantalla es el dispositivo de salida que muestra la información visualmente.

### Opciones
- [ ] A) USB
- [ ] B) Pantalla

### Enunciado
¿Cuál de los siguientes es un dispositivo de ENTRADA (sirve para meter información al PC)?

### Opciones
- [ ] A) Pantalla
- [ ] B) Impresora
- [x] C) Micrófono
- [ ] D) Parlantes

### Explicación Pedagógica
El micrófono "entra" tu voz al computador. Los otros (pantalla, impresora, parlantes) "sacan" información.

### Enunciado
¿Qué es el "Software" del computador?

### Opciones
- [x] A) Los programas y juegos (lo que no se puede tocar)
- [ ] B) El teclado y el mouse

### Enunciado
Si el computador portátil se calienta mucho, tiene un ventilador interno. ¿Para qué sirve?

### Opciones
- [ ] A) Para que suene bonito
- [ ] B) Para limpiar el polvo
- [x] C) Para enfriar los componentes y evitar que se dañen

## Pregunta 10 (Muy Difícil B - Dificultad 5)
**ID:** "CO-TEC-3-partes-computador-001-v10"

### Enunciado
¿Qué pasa si desconectas el computador de la electricidad y no tiene batería?

### Opciones
- [ ] A) Sigue funcionando igual
- [ ] B) Se vuelve más rápido
- [x] C) Se apaga inmediatamente y puedes perder tu trabajo
- [ ] D) Se convierte en una tablet
