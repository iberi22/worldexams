# Pregunta Base: Pasos Lógicos

> **Contexto:** Un algoritmo es una serie de pasos ordenados para realizar una tarea. Los usamos todo el tiempo, no solo en computadores.

---

## Pregunta 1 (Muy Fácil A - Dificultad 1)
**ID:** "CO-TEC-3-algoritmos-vida-001-v1"

### Enunciado
¿Cuál es el ORDEN correcto para cepillarse los dientes?

### Opciones
- [ ] A) Escupir -> Poner crema -> Cepillar -> Enjuagar
- [x] B) Poner crema -> Cepillar -> Escupir -> Enjuagar
- [ ] C) Enjuagar -> Escupir -> Poner crema
- [ ] D) Dormir -> Comer -> Cepillar

### Explicación Pedagógica
Los pasos tienen un orden lógico. No puedes cepillar si no has puesto crema dental primero.

### Enunciado
Para ponerte los zapatos y las medias, ¿qué haces primero?

### Opciones
- [x] A) Ponerse las medias
- [ ] B) Ponerse los zapatos

### Opciones
- [ ] A) Sacar la semilla
- [x] B) Regar con agua

## Pregunta 9 (Muy Difícil A - Dificultad 5)
**ID:** "CO-TEC-3-algoritmos-vida-001-v9"

### Enunciado
Si el algoritmo es "Cruzar la calle", ¿cuál paso condicional ("Si...") es vital?

### Opciones
- [ ] A) Si tengo zapatos, cruzo.
- [x] B) Si el semáforo está en verde para peatones y no vienen carros, cruzo.
- [ ] C) Si está lloviendo, corro.
- [ ] D) Si tengo hambre, cruzo.

### Explicación Pedagógica
Las decisiones (condicionales) son claves: "SI pasa esto, ENTONCES hago aquello". Si el semáforo está rojo, NO cruzo.
