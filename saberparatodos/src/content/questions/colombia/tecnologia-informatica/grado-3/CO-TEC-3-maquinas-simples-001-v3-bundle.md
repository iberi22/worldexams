# Pregunta Base: Ayudantes del Trabajo

> **Contexto:** Las máquinas simples son inventos sencillos que facilitan el trabajo humano, permitiendo aplicar menos fuerza.

---

## Pregunta 1 (Muy Fácil A - Dificultad 1)
**ID:** "CO-TEC-3-maquinas-simples-001-v1"

### Enunciado
¿Cuál de estos objetos es una RUEDA?

### Opciones
- [ ] A) Un libro
- [x] B) La llanta de una bicicleta
- [ ] C) Un martillo
- [ ] D) Una mesa

### Explicación Pedagógica
La rueda es un objeto circular que gira sobre un eje. Es fundamental para el transporte.

## Pregunta 2 (Muy Fácil B - Dificultad 1)
**ID:** "CO-TEC-3-maquinas-simples-001-v2"

### Enunciado
¿Para qué sirve una rampa (plano inclinado)?

### Opciones
- [ ] A) Para dormir
- [x] B) Para subir objetos pesados más fácilmente
- [ ] C) Para cortar papel
- [ ] D) Para cocinar

### Explicación Pedagógica
En lugar de levantar un peso verticalmente, es más fácil empujarlo por una subida suave (rampa).

## Pregunta 3 (Fácil A - Dificultad 2)
**ID:** "CO-TEC-3-maquinas-simples-001-v3"

### Enunciado
¿Qué herramienta usas para clavar una puntilla?

### Opciones
- [ ] A) Destornillador
- [x] B) Martillo
- [ ] C) Serrucho
- [ ] D) Llave

### Explicación Pedagógica
El martillo es una palanca manual que concentra la fuerza en el golpe para clavar objetos.

## Pregunta 4 (Fácil B - Dificultad 2)
**ID:** "CO-TEC-3-maquinas-simples-001-v4"

### Enunciado
Las tijeras son un ejemplo de:

### Opciones
- [x] A) Palanca
- [ ] B) Rueda
- [ ] C) Polea
- [ ] D) Plano inclinado

### Explicación Pedagógica
Las tijeras funcionan cruzando dos hojas (palancas) sobre un punto de apoyo central para cortar.

## Pregunta 5 (Media A - Dificultad 3)
**ID:** "CO-TEC-3-maquinas-simples-001-v5"

### Enunciado
¿Para qué sirve una POLEA (como la de un pozo de agua)?

### Opciones
- [ ] A) Para cortar madera
- [ ] B) Para calentar agua
- [x] C) Para subir objetos jalando una cuerda hacia abajo
- [ ] D) Para pegar cosas

### Explicación Pedagógica
La polea cambia la dirección de la fuerza. Es más fácil jalar hacia abajo con tu peso que levantar algo hacia arriba con tus brazos.

## Pregunta 6 (Media B - Dificultad 3)
**ID:** "CO-TEC-3-maquinas-simples-001-v6"

### Enunciado
¿Cuál de los siguientes objetos tiene un TORNILLO?

### Opciones
- [ ] A) Una hoja de papel
- [x] B) La tapa de una botella de gaseosa
- [ ] C) Una caja de cartón
- [ ] D) Una bolsa

### Explicación Pedagógica
La rosca de la tapa y de la botella funcionan como un tornillo (plano inclinado enrollado) para cerrar herméticamente.

### Enunciado
El sube y baja del parque funciona gracias al principio de:

### Opciones
- [ ] A) La rueda
- [x] B) La palanca
- [ ] C) La cuña

## Pregunta 8 (Difícil B - Dificultad 4)
**ID:** "CO-TEC-3-maquinas-simples-001-v8"

### Enunciado
La cuña es una máquina simple que sirve para separar o cortar objetos. Un ejemplo es:

### Opciones
- [ ] A) Un balón
- [x] B) Un hacha
- [ ] C) Una cuerda

## Pregunta 9 (Muy Difícil A - Dificultad 5)
**ID:** "CO-TEC-3-maquinas-simples-001-v9"

### Enunciado
Si quieres llevar tierra de un lado a otro del jardín, es mejor usar una carretilla porque:

### Opciones
- [ ] A) Se ve bonita
- [x] B) Combina la rueda y la palanca para cargar peso con menos esfuerzo
- [ ] C) La tierra pesa menos en la carretilla
- [ ] D) La carretilla tiene motor

### Explicación Pedagógica
La rueda soporta parte del peso y las manijas actúan como palanca, facilitando el transporte de cargas pesadas.

## Pregunta 10 (Muy Difícil B - Dificultad 5)
**ID:** "CO-TEC-3-maquinas-simples-001-v10"

### Enunciado
¿Qué máquina simple usó Arquímedes cuando dijo "Dadme un punto de apoyo y moveré el mundo"?

### Opciones
- [ ] A) La polea
- [x] B) La palanca
- [ ] C) El plano inclinado
- [ ] D) La rueda

### Explicación Pedagógica
Se refería al poder multiplicador de fuerza de la palanca. Con una palanca lo suficientemente larga, se podría mover cualquier peso.
