# Pregunta Base: Escribiendo en el PC

> **Contexto:** Los procesadores de texto (como Microsoft Word o Google Docs) son herramientas para crear documentos escritos.

**ID:** "CO-TEC-5-procesadores-texto-001-v1"

### Enunciado
¿Cuál de estos es un procesador de texto?

### Opciones
- [ ] A) Paint
- [x] B) Microsoft Word
- [ ] C) Calculadora
- [ ] D) YouTube

### Explicación Pedagógica
Word es el programa más conocido para escribir cartas, tareas y trabajos.

## Pregunta 9 (Muy Difícil A - Dificultad 5)
**ID:** "CO-TEC-5-procesadores-texto-001-v9"

### Enunciado
Si quieres copiar un texto de una página web y pegarlo en Word, la secuencia correcta es:

### Opciones
- [ ] A) Pegar -> Copiar -> Seleccionar
- [x] B) Seleccionar -> Copiar -> Pegar
- [ ] C) Copiar -> Seleccionar -> Pegar
- [ ] D) Seleccionar -> Borrar -> Escribir

### Explicación Pedagógica
Primero debes decirle al computador QUÉ quieres (seleccionar), luego guardarlo en memoria (copiar) y finalmente ponerlo donde quieres (pegar).

## Pregunta 10 (Muy Difícil B - Dificultad 5)
**ID:** "CO-TEC-5-procesadores-texto-001-v10"

### Enunciado
¿Cuál es la diferencia entre "Guardar" y "Guardar como"?

### Opciones
- [ ] A) Son lo mismo
- [x] B) "Guardar" actualiza el archivo actual; "Guardar como" crea una copia con otro nombre/lugar
