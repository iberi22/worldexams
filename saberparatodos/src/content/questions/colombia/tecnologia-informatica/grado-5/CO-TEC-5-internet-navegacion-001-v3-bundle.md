# Pregunta Base: La Red de Redes

> **Contexto:** Internet es una red mundial que conecta computadores para compartir información. Para usarla necesitamos un Navegador.

**ID:** "CO-TEC-5-internet-navegacion-001-v1"

### Enunciado
¿Cuál de estos logos representa un Navegador de Internet?

### Opciones
- [ ] A) El logo de Word (W azul)
- [x] B) El logo de Chrome (Círculo de colores)
- [ ] C) El logo de la Papelera de Reciclaje
- [ ] D) El logo de Paint

### Explicación Pedagógica
Google Chrome, Mozilla Firefox y Microsoft Edge son los navegadores más comunes.

### Enunciado
La dirección de una página web (URL) generalmente empieza con:

### Opciones
- [ ] A) www.algo.com
- [x] B) http:// o https://
- [ ] C) @arroba
- [ ] D) #hashtag

"https" indica el protocolo de comunicación seguro para transmitir la página.

**ID:** "CO-TEC-5-internet-navegacion-001-v7"

### Enunciado
¿Qué es "Descargar" (Download) un archivo?

### Opciones
- [ ] A) Borrarlo de internet
- [x] B) Copiarlo desde Internet a tu computador para tenerlo guardado
- [ ] C) Subirlo a la nube
- [ ] D) Imprimirlo
