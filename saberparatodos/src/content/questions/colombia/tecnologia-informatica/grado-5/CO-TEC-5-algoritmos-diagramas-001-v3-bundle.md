# Pregunta Base: Dibujando Soluciones

> **Contexto:** Los diagramas de flujo son mapas que muestran gráficamente los pasos de un algoritmo usando figuras geométricas.

---

## Pregunta 1 (Muy Fácil A - Dificultad 1)
**ID:** "CO-TEC-5-algoritmos-diagramas-001-v1"

### Enunciado
¿Qué es un Diagrama de Flujo?

### Opciones
- [ ] A) Un dibujo libre de un paisaje
- [x] B) Una representación gráfica de los pasos de un proceso
- [ ] C) Un mapa de Colombia
- [ ] D) Un videojuego

### Explicación Pedagógica
Usa símbolos universales (óvalos, cuadros, rombos) conectados por flechas para explicar cómo funciona algo.

## Pregunta 2 (Muy Fácil B - Dificultad 1)
**ID:** "CO-TEC-5-algoritmos-diagramas-001-v2"

### Enunciado
En un diagrama de flujo, las FLECHAS indican:

### Opciones
- [ ] A) Que es un arcoiris
- [ ] B) Los enemigos
- [x] C) El orden o dirección en que se ejecutan los pasos (flujo)
- [ ] D) Nada

### Explicación Pedagógica
Las líneas de flujo nos dicen "después de este paso, sigue este otro".

## Pregunta 3 (Fácil A - Dificultad 2)
**ID:** "CO-TEC-5-algoritmos-diagramas-001-v3"

### Enunciado
El símbolo del ÓVALO (elipse) se usa para marcar:

### Opciones
- [ ] A) Una decisión
- [x] B) El INICIO y el FIN del algoritmo
- [ ] C) Una operación matemática
- [ ] D) Una impresión

### Explicación Pedagógica
Todo diagrama debe tener un punto de partida (Inicio) y uno de llegada (Fin), representados por óvalos.

### Enunciado
Un "Algoritmo Infinito" es aquel que:

### Opciones
- [ ] A) Es muy largo
- [x] B) Nunca llega a un Fin (se queda en un bucle eterno)
- [ ] C) Es muy inteligente
- [ ] D) Funciona perfecto

### Enunciado
Si tienes que ordenar 5 números de menor a mayor, ¿qué tipo de algoritmo necesitas?

### Opciones
- [ ] A) De búsqueda
- [x] B) De ordenamiento (Sorting)
