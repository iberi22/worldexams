# Pregunta Base: Los dos componentes del PC

> **Contexto:** Un sistema informático se compone de dos partes inseparables: la física (Hardware) y la lógica (Software).

---

## Pregunta 1 (Muy Fácil A - Dificultad 1)
**ID:** "CO-TEC-5-hardware-software-001-v1"

### Enunciado
¿Cuál de los siguientes es un ejemplo de HARDWARE?

### Opciones
- [ ] A) Paint
- [x] B) Teclado
- [ ] C) Windows
- [ ] D) Word

### Explicación Pedagógica
Hardware es todo lo que puedes tocar y golpear si se daña (partes físicas).

---

## Pregunta 2 (Muy Fácil B - Dificultad 1)
**ID:** "CO-TEC-5-hardware-software-001-v2"

### Enunciado
¿Cuál de los siguientes es un ejemplo de SOFTWARE?

### Opciones
- [ ] A) Disco duro
- [ ] B) Impresora
- [x] C) El navegador de internet (Chrome/Edge)
- [ ] D) Cable de poder

### Explicación Pedagógica
Software son los programas, apps y datos. No se pueden tocar físicamente.

## Pregunta 3 (Fácil A - Dificultad 2)
**ID:** "CO-TEC-5-hardware-software-001-v3"

### Enunciado
Un dispositivo de ENTRADA sirve para:

### Opciones
- [x] A) Introducir datos al computador (ej. Teclado, Micrófono)
- [ ] B) Sacar información (ej. Pantalla)
- [ ] C) Guardar archivos (ej. Disco duro)
- [ ] D) Enfriar el PC

### Explicación Pedagógica
Entrada (Input) = Información entra del mundo real al PC.

## Pregunta 4 (Fácil B - Dificultad 2)
**ID:** "CO-TEC-5-hardware-software-001-v4"

### Enunciado
El "Sistema Operativo" (como Windows, Android o Linux) es:

### Opciones
- [ ] A) Un virus
- [ ] B) Un juego
- [x] C) El software principal que controla el computador
- [ ] D) Una parte del teclado

### Explicación Pedagógica
Sin sistema operativo, el hardware no sabría qué hacer. Es el "jefe" de los programas.

## Pregunta 6 (Media B - Dificultad 3)
**ID:** "CO-TEC-5-hardware-software-001-v6"

### Enunciado
La memoria RAM sirve para:

### Opciones
- [ ] A) Guardar fotos para siempre
- [x] B) Guardar datos temporalmente mientras el computador está prendido
- [ ] C) Imprimir
- [ ] D) Conectarse a internet

### Explicación Pedagógica
Es la memoria de trabajo. Si apagas el PC, lo que hay en la RAM se borra (por eso debes guardar en el Disco Duro).

¿Qué significa CPU?

## Pregunta 8 (Difícil B - Dificultad 4)
**ID:** "CO-TEC-5-hardware-software-001-v8"

### Enunciado
Un "Driver" o Controlador es un tipo de software que:

### Opciones
- [ ] A) Maneja un carro en un juego
- [x] B) Permite que el Sistema Operativo se comunique con el Hardware (ej. driver de impresora)

## Pregunta 9 (Muy Difícil A - Dificultad 5)
**ID:** "CO-TEC-5-hardware-software-001-v9"

### Enunciado
¿Cuál es la función del Disco Duro (Hard Disk / SSD)?

### Opciones
- [ ] A) Procesar datos
- [x] B) Almacenamiento permanente de información (aunque se apague el PC)
- [ ] C) Mostrar imágenes
- [ ] D) Conectar a internet

### Explicación Pedagógica
A diferencia de la RAM, el almacenamiento secundario (Disco duro/SSD) guarda tus archivos a largo plazo.

## Pregunta 10 (Muy Difícil B - Dificultad 5)
**ID:** "CO-TEC-5-hardware-software-001-v10"

### Enunciado
El "Círculo de Procesamiento de Información" tiene 4 pasos. ¿Cuál es el orden lógico?

### Opciones
- [ ] A) Salida -> Proceso -> Entrada -> Almacenamiento
- [x] B) Entrada -> Proceso -> Salida -> Almacenamiento
- [ ] C) Almacenamiento -> Salida -> Entrada -> Proceso
- [ ] D) Proceso -> Entrada -> Salida -> Almacenamiento

### Explicación Pedagógica
1. Ingresas datos (teclado). 2. CPU procesa. 3. Muestra resultado (pantalla). 4. Guardas el archivo.
