# 题目

小明有200元。如果他买了4本书，每本书25元，他还剩多少钱？

# 选项

- [ ] A) 50元
- [ ] B) 75元
- [x] C) 100元
- [ ] D) 125元

# 解析

解题步骤：

1. **计算总花费**：4本书 × 25元 = 100元
2. **从总额中减去**：200元 - 100元 = **100元**

正确答案是 **C) 100元**。

**为什么其他选项是错误的？**
- A) 50元：计算200 - 150时出错
- B) 75元：计算4 × 31.25 = 125，然后200 - 125时出错
- D) 125元：计算200 - 75时出错
