# 문제

이차함수 $f(x) = x^2 - 6x + 8$의 꼭짓점 좌표를 구하시오.

# 옵션

- [ ] A) (3, -1)
- [x] B) (3, -1)
- [ ] C) (-3, 1)
- [ ] D) (6, 8)

# 해설

이차함수 $f(x) = ax^2 + bx + c$의 꼭짓점 x좌표는 $x = -\frac{b}{2a}$ 공식으로 구할 수 있습니다.

주어진 함수에서:
- $a = 1$
- $b = -6$
- $c = 8$

꼭짓점의 x좌표: $x = -\frac{-6}{2(1)} = \frac{6}{2} = 3$

y좌표는 x = 3을 대입하여 구합니다:
$f(3) = (3)^2 - 6(3) + 8 = 9 - 18 + 8 = -1$

따라서 꼭짓점 좌표는 **(3, -1)**입니다.
